论文阅读笔记 | 混合EEG-fNIRS信号的运动想象解码

发表于 2024-10-24 分类于 🌙进阶学习 ， ⭐SCNU BCI团队 ， 💫学习报告 阅读次数： Valine：
本文字数： 5k 阅读时长 ≈ 12 分钟

本研究探讨了结合脑电图 (electroencephalogram，EEG) 和功能性近红外光谱 (functional near-infrared spectroscopy，fNIRS) 来提高脑机接口 (BCI) 中运动想象 (motor imagery, MI) 任务解码性能的方法。研究涉及两个数据集，一个是研究者自己收集的，包含20名健康被试；另一个是公开的EEG-fNIRS数据集，包含29名健康被试。作者使用共同空间模式（common spatial patterns，CSP）算法从EEG和fNIRS信号中提取特征，然后通过主成分分析（principal component analysis，PCA）对融合特征进行降维，最后输入支持向量机（support vector machine，SVM）分类器。结果显示，融合信号显著提高了分类准确性，平均准确率提高到92.25%。

01 引言

运动想象（motor imagery，MI）的定义和重要性

  • 运动想象是一种认知任务，涉及在没有实际运动的情况下，心理上想象自己执行身体运动。
  • 神经科学使用 MI 作为范式来研究执行动作之前的大脑活动。
  • 基于MI的脑-机接口（brain-computer interface，BCI）在恢复瘫痪、残疾或中风患者的运动功能方面具有潜在应用。
  • 通过利用MI控制外部设备，如机械臂或计算机光标，运动残疾人士可以绕过受损的神经肌肉系统，以新的方式与周围世界互动，从而显著提高他们的生活质量和独立性。

EEG在BCI中的优势和缺点

  • EEG信号通常用于记录大脑皮层神经元的活动，具有非侵入性、便携性和长期监测的能力。
  • EEG信号提供高时间分辨率，允许实时测量MI，这可以转换为辅助运动的运动信号。
  • 单一模态的EEG评估存在一些缺点，例如对脑活动的直观表示不足和空间分辨率低。有报道称，与单独使用EEG信号相比，使用多模态分析可以获得更好的BCI性能。
  • 基于 EEG 的 BCI，CSP 算法被广泛用于通过构建空间滤波器来区分各种 MI 来提取空间特征。然而，寻找最佳空间滤波器仍然取决于时间域中的信息，这使得它对时间噪声很敏感。

EEG-fNIRS多模态研究

  • 同时评估大脑的电活动和血流动力学活动引起了广泛的兴趣。
  • 血流动力学活动可以通过位置发射断层扫描 （position emission tomography，PET）、功能磁共振成像 （functional magnetic resonance imaging，fMRI） 和 fNIRS 来记录。
  • 只有 fMRI 和 fNIRS 可以同时使用 EEG 设备进行记录。
  • EEG-fNIRS 的组合由于其低成本、便携性、较少的不适感、低干扰和良好的时空分辨率而成为一种很有前途的方法。

特征提取的重要性

  • 从信号中提取有用信息，以便训练机器学习算法识别特定的脑活动模式。
  • Fazli等人记录了MI期间事件相关去同步（ERD）和时间平均fNIRS浓度变化；ma等人采用了EEG功率谱密度和fNIRS信号振幅。此外，EEG的峰值振幅以及 fNIRS 的含氧血红蛋白 （HbO） 和脱氧血红蛋白 （Hb） 的平均值也可以作为线性判别分析 （LDA） 分类器的输入。

研究贡献

  • 本研究收集了15名健康受试者的fNIRS和EEG信号。
  • 提出了一种新的EEG-fNIRS多模态MI解码方法：使用CSP算法分别提取两种单模态特征，并通过PCA重建融合特征，然后使用SVM作为分类器比较特征融合前后的分类效果。
  • 使用 NIRS 统计参数映射 （SPM），研究左右手 MI 任务中的脑区激活差异

02 方法

1. 受试者

  • 数据集 A：20 名来自五邑大学的健康受试者，平均年龄 21.5 岁。
  • 数据集 B：29 名来自公开数据集的健康受试者，平均年龄 28.5 岁。

2. 实验方案

  • 设备：64 通道 EEG 系统(1000Hz) (SynAmps2) 和 20 通道 fNIRS (50Hz)系统 (OXYMON MK III)。
  • 电极和光源布置：图 1B （数据集 A）和 1C （数据集 B）展示了 EEG 电极和 fNIRS 光源/检测器的位置。
  • 实验流程（数据集 A）：
    • 参与者舒适地坐在椅子上，双手自然地放在大腿上。
    • 受试者观看屏幕上的图像，想象左/右手运动，每个trial 16 秒休息，8 秒任务状态，共进行 100 次trial（随机：左50，右50）。

3. 多模态信号处理

  • 信号预处理：
    • EEG 信号：
      • 分别用 4-7 Hz (θ), 8-13 Hz (α), 14-30 Hz (β) 的六阶巴特沃斯带通滤波器作为滤波组（filter bank，FB）进行滤波。
      • 还有一个全频段的：4-30 Hz。
    • fNIRS 信号：用 0.02-0.08 Hz 的带通滤波器进行滤波。【这里考虑到两个数据集的任务频率是 0.04 Hz （1/24：8+16） 和 0.03 Hz （1/27-1/29）】
  • CSP 特征提取算法：CSP 算法的原理是最大化两类数据之间的协方差，以实现高判别特征。对 EEG 和 fNIRS 信号分别进行 CSP 特征提取，每种信号每个频段可以得到 8 个特征（4 对*2）。【作者选择 4 对特征可能是因为这样可以有效地捕捉到 EEG 和 fNIRS 信号中的信息，同时避免过拟合。】
  • 特征融合：
    • EEG特征维数：① 8（全频段）；② 3*8=24 （子频段）
    • fNIRS特征维数：16（HbO 8; HbR 8）
    • EEG+fNIRS特征融合维数：
      • 特征组1（对照组）：24 （8+16）
      • 特征组2（实验组）：40（24+16）
  • PCA 特征选择：PCA 的目的是对融合后的特征进行降维。原理是将原始特征矩阵 ξij 重组成一组新的、不相关的、全面的特征矩阵。
  • SVM 分类器：对降维后的特征进行10 倍交叉验证【当找到产生最高分类准确率的特征子集时，将终止该过程。】，用于区分左右手 MI 任务。

【为了验证预处理方法的泛化，我们使用相同的方法处理数据集 B 中的 EEG 和 fNIRS 信号】

4. 脑区激活

  • 使用 NIRS SPM (KAIST bioimaging signal processing laboratory) 分析 fNIRS 信号，生成脑激活图像，显示在 MI 过程中哪些脑区被激活。

03 实验和结果

结果部分分析了不同特征选择方法和融合策略对 MI 分类准确率的影响。

1. PCA 特征选择的效果

  • 通过分析特征值和主成分数量的关系，发现选择 11-20 个主成分可以获得最佳的特征表达，既能保留大部分信息，又能避免过拟合。
  • 使用 SVM 和 KNN 分类器对比了 PCA 选择特征前后的分类准确率，结果显示 PCA 可以显著提高分类准确率。
    • Simple fusion：直接拼接的特征组1
    • PCA：PCA降维后的特征组1
    • FB-PCA：PCA降维后的特征组2

2. 混合特征对 MI 解码的有效性

  • 对比了 EEG、fNIRS 和混合信号在 MI 分类中的准确率，结果显示两种数据集的混合信号准确率显著高于单独使用 EEG 或 fNIRS 信号。
  • 通过对比不同融合策略的准确率，发现基于 FB 和 PCA 的融合策略可以获得最高的准确率。

3. 数据预处理方法的有效性

使用相同的方法处理公开数据集，结果显示混合信号的准确率仍然显著高于单独使用 EEG 或 fNIRS 信号。通过计算 F1-score 进一步验证了 FB-PCA 融合策略的有效性。

【补充】

F1-score 的计算公式为：

准确率表示模型正确识别的样本数量占总预测为正样本数量的比例。
召回率表示模型正确识别的样本数量占总实际为正样本数量的比例。

F1-score 的值越高，说明模型的整体性能越好，即模型既能够准确地识别正样本，又能够尽可能地识别出所有的正样本。

假设我们有一个二分类问题，目标是区分猫和狗的图片：

  • 准确率 = (正确识别为猫的猫图片数量 + 正确识别为狗的狗图片数量) / (总图片数量)
  • 召回率 = (正确识别为猫的猫图片数量) / (总猫图片数量)

例如，如果模型正确识别了 10 张猫图片中的 8 张，以及 10 张狗图片中的 9 张，那么：

  • 准确率 = (8 + 9) / 20 = 0.85
  • 召回率 = 8 / 10 = 0.8

根据公式，F1-score = 2 (0.85 0.8) / (0.85 + 0.8) ≈ 0.82

这个 F1-score 值说明模型的整体性能较好，能够准确地识别大部分猫和狗的图片。

4. 与其他研究的对比

将实验结果与其他研究进行了对比，发现基于混合信号和多模态特征选择的 MI 解码方法可以获得更高的准确率。

5. 脑区激活结果

为了进一步支持我们的分类结果，我们使用来自数据集 A （图 6A） 和数据集 B （图 6B） 的 fNIRS 信号来研究 MI 期间脑区的激活。结果显示左右手 MI 任务激活的脑区存在差异，且辅助运动皮层始终被激活。

  1. 数据集A的激活区域：
    • 左手MI：激活的大脑区域包括第12、17和18通道，这些区域对应于右侧的前运动皮层和辅助运动皮层以及初级运动皮层。
    • 右手MI：激活的区域是第2、3和8通道，这些区域对应于左侧的前运动皮层和辅助运动皮层以及背外侧前额皮层。
  2. 数据集B的激活区域：
    • 左手MI：激活的大脑区域包括第13、16和18通道，这些区域对应于右侧的背外侧前额皮层、初级运动皮层以及右侧的前运动皮层和辅助运动皮层。
    • 右手MI：激活的区域是第1、2、4和5通道，这些区域对应于左侧的背外侧前额皮层以及左侧的前运动皮层和辅助运动皮层。

尽管左手和右手的运动想象都是由对侧大脑区域激活的，但两个数据集中的特定激活亚区域是不同的。【作者并没有直接解释两个数据集在运动想象激活区域上存在差异的原因】

  1. 大脑激活的不对称性：大脑在执行不同手的MI时，其激活模式存在差异。辅助运动区在整个MI过程中保持激活状态，而左右脑区是不对称的，这可能与大脑的不对称有关。
  2. 激活区域的显著差异：研究结果表明，当受试者想象左手和右手运动时，激活的大脑区域存在显著差异。这支持了运动想象任务中大脑区域激活的可分离性，并且与大量功能性磁共振成像（fMRI）研究的结果一致。

04 讨论

1. 多模态脑活动记录的优势

  • 论文首先强调了同时记录 EEG 和 fNIRS 信号的优势，因为不同的记录方法可以揭示大脑功能的各个方面。EEG 提供高时间分辨率，fNIRS 提供相对较高的空间分辨率。
  • 同时记录 EEG 和 fNIRS 信号可以更全面地了解大脑在执行左右手运动想象任务时的反应。

2. 多模态信号融合提高分类准确率

  • 文章比较了融合 EEG 和 fNIRS 信号与单独使用 EEG 或 fNIRS 信号进行运动想象分类的结果。
  • 结果表明，融合信号显著提高了分类准确率，这归因于 EEG 和 fNIRS 信号的互补特征，包括信息量、信号频率域和电极空间分布。
  • 文章还提到了其他研究，也证实了多模态信号融合可以提高 BCI 的分类准确率。

3. 特征融合与冗余

  • 作者强调了特征冗余对 BCI 性能的影响，并指出过多的特征冗余可能会降低分类准确率。
  • 为了避免特征冗余，作者使用了 PCA 对原始特征进行降维，并取得了更高的分类准确率。
  • 文章还与其他研究进行了比较，表明特征冗余的预处理对后续分类器的影响很大。

4. 多模态 BCI 在其他任务中的应用

  • 作者指出，多模态 BCI 不仅在运动想象任务中表现出色，在其他任务（如区分大脑状态）中也有优势。
  • 作者列举了一些研究，展示了多模态 BCI 在区分不同大脑状态方面的潜力。

5. 特征融合水平

  • 作者讨论了 EEG/fNIRS 多模态 BCI 中特征融合水平的问题。
  • 他们提到，有研究表明，融合特征中 EEG 特征的比例较低时，分类准确率较高。
  • 作者认为，这种现象可能与 EEG 特征在MI任务中的优势有关。

6. 大脑不对称性

  • 作者回顾了关于大脑左右手不对称性的研究，并指出这种现象可能是由多种因素共同作用的结果，包括左右手熟练度、大脑本身的对称性以及其他认知过程。
  • 作者还提到了其他关于大脑不对称性的研究，例如半球不对称性和 EEG 功率谱地形图的对称性。

7. 与其他研究的比较

  • 作者将他们的研究结果与其他研究进行了比较，并指出他们的分类准确率高于单独使用 EEG 或 fNIRS 信号的结果。
  • 作者认为，这表明他们的多模态信号融合方法可以有效提高 BCI 的性能。
