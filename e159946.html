从 EEG 波形到结果：CNN 如何学习脑电特征

发表于 2026-09-16 分类于 🌙进阶学习 ， ⭐SCNU BCI团队 ， 💫基础知识 阅读次数： Valine：

在前面的文章中，我们已经完成了两件非常重要的事情：首先，把采集到的原始 EEG 经过滤波、去伪迹、重参考、分段等预处理，得到相对干净、可以进一步分析的脑电信号；随后，从这些 EEG 中提取均值、方差、Hjorth 参数、频带功率、时频特征、CSP 空间特征等人工设计的特征，再将它们交给 LDA、SVM、Random Forest 等传统机器学习模型进行分类。

传统机器学习的基本流程可以概括为：

这套方法并没有因为深度学习出现而过时。在数据量较小、需要较强可解释性或计算资源有限的场景中，人工特征仍然非常有价值。但它带来了一个自然的问题：如果不再提前规定”什么才是有用特征”，模型能不能直接从 EEG 波形中自己学习？

本文聚焦其中一种方法：卷积神经网络（Convolutional Neural Network，CNN）。CNN 通过可训练的卷积核，从 EEG 中学习局部时间模式和通道组合，再把这些表示交给分类层。这里的“自动”是指特征提取参数可以随任务一起训练，而不是取消预处理和实验设计。

我们将围绕一个具体问题展开：一段 EEG 进入 CNN 后，怎样从多通道波形变成类别预测？ 从卷积核、特征图、池化和感受野讲起，再理解时间卷积、空间卷积与时频图输入，再以 EEGNet 这一里程碑式模型理解 EEG 专用 CNN 的设计，最后用一个可运行的运动想象分类网络把数据形状和训练过程串起来。

直观来看，卷积核就像一个很短的”波形探测器”。它不断观察 EEG 的局部片段，并根据训练得到的权重判断这一小段信号是否包含与任务相关的模式。

CNN 与传统数字滤波存在一定直觉上的相似性：二者都对局部信号进行加权组合。但 CNN 卷积核的参数并不是根据 Butterworth、Chebyshev 等滤波器设计方法预先计算，而是通过任务损失和反向传播学习得到。因此可以把卷积核理解为一种由任务驱动学习出来的局部特征提取器，但不能把每一个卷积核都严格等价成传统带通滤波器。

但需要特别强调：把 EEG 转换成二维矩阵，并不意味着 EEG 就真的变成了自然图像。 自然图像的横纵轴主要对应空间位置，而 EEG 时频图的两个轴分别表示时间和频率，物理意义完全不同。因此不能因为 Shape 类似图像，就无条件照搬所有计算机视觉假设。

CNN 擅长提取局部模式，但一个输出位置能利用多少输入信息，取决于网络的感受野。卷积核较短、层数较少时，模型可能难以覆盖任务所需的较长时间范围。

在 CNN 内部，可以通过更长的卷积核、更多卷积层、多尺度分支或空洞卷积扩大观察范围。空洞卷积在相邻卷积采样位置之间留出间隔，能在不增加核内权重数量的情况下扩大覆盖范围，但也要注意过于稀疏的采样可能遗漏局部细节。

另一方面，池化和全局汇聚会压缩时间信息。全局平均池化擅长概括“某类响应整体有多强”，却不一定保留“它准确发生在哪个时间点”。如果目标是识别精细 ERP 潜伏期，应谨慎设置池化尺度和分类头。

实时 BCI 还需要考虑因果性：对称 padding 的普通卷积可能使用当前时刻之后的采样点。离线窗口分类可以在窗口收集完成后计算，但若要求逐点实时输出，就需要因果卷积或明确允许的延迟。

因此，设计 CNN 时应先确定：任务需要多长的上下文，以及哪些时间位置关系必须保留下来。

四、EEGNet：Deep Learning in BCI 的里程碑式模型

大部分初学者学习深度学习在脑机接口当中的应用都绕不开EEGNet——这个堪称里程碑式的模型。如果读者打算从事DL in BCI方面的研究工作建议反复研读这篇文章，彻底理解时间卷积和空间卷积到底在做什么？原理是什么？这篇论文都讲的十分清楚。对于刚入门深度学习应用到脑机接口当中的读者去读一些前沿的EEG model paper肯定会晕头转向，其实他们的设计原型都来自于EEGNet和ConvNet这些经典的文章。读到这里的读者属实不容易，最近文章篇章写的有一点长全部都是干货，整理文章的同时也消耗了大量的时间。下面将介绍一下个人的见解，也对读到这里所有读者表示感谢。现在百分之九十或者以上EEG model的设计都是借助于计算机视觉，自然语言处理等其他前沿领域的模型架构设计，各位朋友不妨去研读一些其他领域前沿的文章寻找设计思路。

在理解 CNN 的基本运算之后，EEGNet 是一个值得单独认识的模型。我们可以将 EEGNet 称为 Deep Learning in BCI（脑机接口中的深度学习）的里程碑式模型：它的重要意义，在于把 EEG 特征提取的领域知识与紧凑的卷积结构结合起来，探索同一种网络架构在不同 BCI 范式中的适用性。

EEGNet的论文复现代码仓库在链接https://github.com/XCZchaos/python-implementation-of-motion-imagination-classification/tree/main 当中的New train folder文件夹当中，读者可以自己试着跑一下，一般的显卡都能进行实验无高配置要求。

Lawhern 等人在《EEGNet: A Compact Convolutional Network for EEG-based Brain-Computer Interfaces》中，围绕 P300、错误相关负波 ERN、运动相关皮层电位 MRCP 和感觉运动节律 SMR 四类范式进行了比较。“里程碑式”是对其方法意义的概括，并不是指它在所有数据集上都取得最高准确率；跨范式适用也不等于一个训练好的模型可以不经适配直接识别所有任务。参见 EEGNet 原始论文。

2. 时间卷积：在每个电极上寻找局部波形模式

时间卷积（Temporal Convolution）主要回答：这一小段波形在时间上呈现什么模式？ 它的卷积核形状为 $(1,K)$ ：高度为 1，说明一次只处理一个电极；宽度为 $K$ ，说明一次观察连续 $K$ 个采样位置。

3. 空间卷积：把多个电极组合成新的信号

时间卷积之后，我们已经知道各电极上存在怎样的时间响应。接下来的问题是：哪些电极的响应应该共同增强，哪些应该相互抵消，才能突出任务差异？ 这就是这里的空间卷积（Spatial Convolution）要学习的内容。

4. Depthwise 与 Separable：怎样减少参数并分开学习不同关系

时间卷积、空间卷积描述“沿哪个轴处理”；depthwise、pointwise 描述“怎样连接特征通道”。 它们不是同一层面的分类，所以一个卷积既可以是空间卷积，也可以是 depthwise 卷积。

EEGNet 的空间卷积采用 depthwise 连接方式：每一种时间特征单独学习自己的空间滤波器，不在这一步混合不同时间特征。 $D=2$ 表示每一种时间特征学习两套电极权重。因此，8 种时间特征会产生 16 种时空特征。

Batch Normalization 用于调整中间特征的数值分布，并带有可学习的缩放和平移参数；它不是对原始 EEG 的去伪迹操作。训练时使用 batch 统计量并更新运行统计量，默认推理模式使用保存的运行统计量，所以验证和测试要调用 model.eval()。

ELU 提供非线性。例如取 $\alpha=1$ 时，正输入保持原值，负输入映射为 $e^x-1$ 。它让网络能够表达仅靠线性时间滤波和空间加权无法得到的映射。EEGNet 的这段结构不是每做一次卷积就立即加一个激活：时间卷积与空间卷积之间有归一化，但非线性激活在空间组合之后。

平均池化压缩时间轴，Dropout 在训练阶段随机丢弃部分响应以减轻过拟合。池化后的值是网络特征响应的平均，不应直接称为某个频带的功率；如果没有平方或相应能量计算，平均响应与平均功率不是同一个量。

上述 EEGNet 结构在展平后接分类层；作者实现最后还用 Softmax 输出概率。若用 PyTorch 的 CrossEntropyLoss 训练，则应让模型返回 logits，由损失函数处理归一化；需要展示概率时再计算 Softmax。后面的简化 CNN 示例使用全局平均池化，而本章结构采用展平，这两种分类头不能混为一谈。

6. 怎样选择参数，并理解模型真正学到了什么

EEGNet- $F_1,D$ 的命名突出时间滤波器数和每个时间特征的空间滤波器数。因此 EEGNet-8,2 的含义不是“8 根电极、2 个类别”，而是 8 种时间滤波和每种时间滤波下的 2 种空间组合。论文中的紧凑设计与这些连接方式有关。参见原论文的网络结构说明。

实际设置时，应把卷积核长度换算成秒，再考虑任务。相同的 64 点时间核，在 128 Hz 下约为 0.5 秒，在 250 Hz 下约为 0.256 秒，覆盖的时间不同。改变采样率后，不能只修改输入长度而不检查时间核和池化尺度。

池化之后，后续卷积处理的也不是原始采样点。以本章示例为例，第一次池化的步长为 4，后续相邻特征位置对应原始输入中相隔 4 个采样点。第二段长度为 16 的时间核会覆盖更长的原始时间范围，而且它的完整感受野还包括前面卷积和池化的覆盖，不能仅用 $16/250$ 秒来解释。

增大 $F_1$ 或 $D$ 可以增加候选特征，也会增加拟合自由度。应在训练和验证数据内选择这些参数，而不是根据测试集反复调整。电极数量、顺序、参考方式、窗口长度和缩放规则也必须在训练与实际使用时对应。

最后，EEGNet 的结构让时间滤波和空间组合更容易被分别检查，但“容易检查”不等于“自动获得生理解释”。一个有判别力的响应可能来自任务相关节律，也可能来自眼电或肌电。应结合输入质量、滤波器响应、空间模式和独立验证判断模型使用的信息。

把这章连起来理解，EEGNet 学习的是：先以多种时间模式观察每根电极，再为各类时间响应学习空间组合，随后汇总并融合这些特征，最终服务于分类任务。 这也是它作为 Deep Learning in BCI 里程碑式模型最值得理解的设计思想。

五、CNN 如何训练，以及怎样判断它是否有效

使用 CNN 之前，仍然要做好信号质量控制。CNN 可以减少人工特征工程，但 EEG 中仍然可能存在电源噪声、电极脱落、运动伪迹、眼电、肌电、基线漂移、坏通道、参考差异和设备差异。

模型并不知道哪些变化是”脑活动”，哪些变化是”采集问题”。更危险的是，如果某种伪迹恰好与标签相关，模型可能非常成功地利用伪迹完成分类。例如类别 A 总是在实验前半段采集，类别 B 总是在后半段采集，而后半段电极阻抗发生系统性变化，模型就可能利用这种非任务因素。

因此：深度学习减少的是人工特征设计，不等于取消信号质量控制。

六、把流程串起来：左右手运动想象的 CNN 示例

现在把本文内容串起来。先明确解码任务，以及要评价同一受试者的新试次、跨 session，还是新受试者。按对应层级划分训练集、验证集和测试集，并确保重叠窗口不会跨集合出现。

例如，若用每个通道的均值和标准差缩放输入，应只在训练集上估计这些统计量，再应用到验证集和测试集。数据增强只用于训练数据；验证和测试时应切换到 model.eval()，使 Dropout 等模块按推理方式工作。

固定参数的逐记录处理可以提前计算，但不能让待评价数据参与跨样本参数估计或模型选择。CNN 是否有效，最终要看它能否在与目标场景一致的独立数据上保持表现。

七、理解 CNN 的能力，也理解它的边界

深度学习出现以后，传统 EEG 特征并没有失去意义。传统特征往往具有明确先验和更直接的解释。例如 $P_{\alpha}$ 具有明确的频带含义，CSP 具有明确的空间滤波和方差判别思想；而深度网络中的 Feature_37 通常没有如此直接的生理解释。

增加卷积层、特征通道和分类层宽度，会提高模型容量，但也可能带来过拟合、更高的计算开销和更大的实时延迟。小规模 EEG 数据集不一定适合很深、很宽的 CNN。

可以先建立规模适中的 CNN 基线，再根据训练与验证结果调整卷积核、感受野和正则化强度。比较结构时，应使用相同的数据划分和评价标准。

更复杂的 CNN ≠ 更可靠的结果。

真正需要关注的是模型是否在独立数据上学到了能够泛化的任务相关模式。

不过，优化目标是降低任务损失，并不保证每个卷积核都对应一个明确的脑电节律。解释模型时仍应结合输入质量、频率响应、消融实验和跨数据验证，不能只根据某张特征图就下生理结论。

总结

这篇文章围绕 CNN 说明了 EEG 自动特征学习的基本过程：卷积核沿时间寻找局部模式，多通道权重学习通道组合；激活函数提供非线性，池化和特征汇聚压缩表示，分类层把这些表示转换为类别分数。

从人工特征到 CNN，改变的是特征形成的方式。高质量输入、合理的数据划分和可靠的验证，仍然是脑机接口解码的基础。
