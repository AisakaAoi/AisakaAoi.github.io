IEEE TAI | 可穿戴脑机接口通过实时神经反馈缓解晕船症状

发表于 2026-02-27 分类于 🌙进阶学习 ， ⭐SCNU BCI团队 ， 💫学习报告 阅读次数： Valine：
本文字数： 4.5k 阅读时长 ≈ 11 分钟

该论文发表于IEEE Transactions on Artificial Intelligence（IEEE旗下人工智能领域权威期刊），题目为《Alleviating Seasickness through Brain–Computer Interface-based Attention Shift》。

华南理工大学的包晓雨博士和许凯琳博士为此文共同第一作者，华南理工大学、琶洲实验室和华南脑控公司的李远清教授和黄骐云教授为通讯作者。合作单位还包括华南师范大学人工智能学院。

论文链接

https://doi.org/10.1109/TAI.2026.3653362

论文概要

晕船是海上出行与作业中困扰无数人的难题。数据显示，约 64% 的新手邮轮乘客会出现晕船症状，在风浪较大的海域，发生率甚至可达 100% 。对于海军人员而言，两栖作战演习中晕船发生率高达 62.5% ，远洋医疗任务中更是达到 72.35% 。药物虽能缓解症状，但头痛、口干、嗜睡等副作用让人望而却步，在医疗资源有限的远海环境中更是难以依赖。真正安全有效的非药物方案在哪里？

华南理工大学李远清教授团队开发出一款人工智能驱动的可穿戴脑机接口系统，让”用意念对抗晕船”成为现实。这款智能头环能实时读取用户的大脑状态，通过精美的视听场景引导注意力从身体的眩晕恶心感自然流向正念冥想练习，从而在真实海洋航行中持续缓解晕船症状。

研究团队招募了43名志愿者，在珠江口海域的真实航行中完成了严苛测试：90分钟的实船航行，对比真实神经反馈、伪反馈和单纯休息三种状态。结果显示，81.39%的参与者确认真实反馈状态有效，且晕船越严重的人受益越大。更关键的是，团队发现了晕船的脑电”指纹”——总频段功率降低、theta相对功率下降、beta相对功率升高，以及注意力指标theta/beta比值的显著降低，为这项技术为何有效提供了科学依据。

这是首个在真实海洋环境中验证的基于脑机接口注意力转移的晕船干预方案。它不仅为亿万海上出行人群带来了航行自由的希望，更将脑机接口技术从实验室推向了远洋作业的新场景。

研究背景

晕船是典型的晕动症，症状从轻微头晕、面色苍白到剧烈呕吐不等，严重时让人对海上出行心生恐惧。约64%的新手邮轮乘客会出现晕船症状，在恶劣海况下发生率可达100%。对于海军和海事人员，晕船不仅降低舒适度，更严重威胁任务执行效率——两栖作战演习中晕船发生率高达62.5%，远洋医疗任务中更是达到72.35%。开发安全有效的干预方案，一直是神经科学与人机交互领域的重要课题。

现有药物如茶苯海明、异丙嗪、赛克利嗪和东莨菪碱等，有效率约62%-78%，但伴随的头痛、口干、嗜睡、视物模糊等副作用，让许多船员和乘客宁愿忍受晕船也不愿服药。在海军环境中，某些药物因高风险特性受到严格限制，进一步加剧了用药困境。非药物干预方面，注意力转移法通过引导注意力转向呼吸控制、音乐欣赏或认知任务来缓解症状，因其无需外部设备而备受青睐，但在持续颠簸的真实海面上维持专注谈何容易？其效果也缺乏严格验证。

如何在动态海洋环境中帮助用户稳定维持注意力，成为突破的关键。海洋航行特有的长时间暴露、剧烈摇摆运动，以及视觉与前庭觉的强烈冲突，使得传统注意力转移方法难以奏效。

研究方法

李远清团队将正念冥想低认知负荷任务与脑机接口技术相结合，打造出一套 “ 懂大脑、会反馈 “ 的智能系统。这套系统由三部分组成：一条轻便的脑电采集头环、运行智能算法的客户端软件、以及沉浸式的视听反馈界面。

头环采用单通道设计，采样率250Hz，电极置于右侧前额叶（Fp2），参考电极和接地电极位于双侧颞部。电极采用水凝胶材料，无需传统导电膏，佩戴舒适且便于清洁。头环内置信号放大电路、蓝牙无线传输模块和可充电锂电池，真正做到了便携易用。

计算终端接收脑电信号后，通过预训练的跨被试卷积神经网络模型进行实时分析。该模型基于213名健康志愿者的数据训练，采用10折交叉验证确保泛化能力，达到76.17%的分类准确率和79.84%的正念状态检出率。系统无需针对个人校准，就能将复杂的脑电信号转化为直观的”注意力分数”（0-100分）。分数越高，代表用户越专注、越沉浸于正念状态。

分数实时驱动着冥想场景的变化。系统提供篝火冥想等多种主题，由专业冥想教练设计并配有指导语。以”篝火冥想”为例：用户通过深呼吸和静默数息提升专注度，当心神宁静时，篝火会愈燃愈旺，木柴噼啪声愈发清晰；一旦思绪飘走，画面便暗淡下去。这种即时反馈如同一位无声的冥想教练，帮助用户觉察状态、调整呼吸，将注意力稳稳锚定在呼吸计数上，自然远离身体的眩晕恶心感。

值得一提的是，这套系统完全兼容Android等移动平台，普通平板电脑即可运行。用户只需10-20分钟的简短培训就能上手，真正做到了”开箱即用”。

为验证效果，研究团队严格筛选了43名健康志愿者，在珠江口海域的真实航行中开展实验。实验在中国水产科学研究院提供的399吨级科考船上进行，航程约80海里，风速约6m/s，浪高约1米，持续约10小时。

实验采用随机交叉设计，每位参与者完成三个90分钟的实验阶段，间隔至少20分钟：

真实反馈正念状态（RMS）：使用BCI系统进行正念冥想，实时神经反馈驱动视听场景变化

休息状态（RS）：静坐休息，无任何干预

伪反馈正念状态（PMS）：观看与RMS相同的视听场景，但反馈基于训练阶段记录的数据叠加高斯噪声，与实时脑电无关

研究人员每10分钟记录一次晕船严重程度评分（MISC，0-10分，分数越高症状越重），并在实验结束后收集7点李克特量表的主观反馈。

实验结果

BCI缓解晕船效果显著，重度患者获益更明显

主观反馈显示，35名参与者（81.39%）认可真实反馈正念状态下BCI干预的有效性，而伪反馈状态下69.77%的参与者表示症状未缓解，两组差异显著（配对t检验：t(42)=-6.816, P < 0.001, Cohen’s d = -1.039）。

客观评分方面，重复测量方差分析显示状态与时间存在显著交互效应（F(18)=4.205, P < 0.001）。初始时刻三组MISC评分无差异，但从第20分钟起，RMS组的MISC评分显著低于RS组（所有10分钟时间点P < 0.05，FDR校正），且全程抑制了评分随时间上升的趋势。最终，RMS组的平均MISC评分（1.063 ± 0.200）显著低于RS组（2.607 ± 0.316，t(42)=-4.128, P < 0.001, Cohen’s d = -0.630）和PMS组（2.486 ± 0.318，t(42)=-3.785, P < 0.001, Cohen’s d = -0.578），而后两组无显著差异。

分层分析进一步揭示，BCI对重度晕船人群效果更佳。将RS阶段MISC评分≥4的参与者归为重度组（n=12），<4分为轻度组（n=10）。重度组的症状缓解幅度（平均3.85分）远超轻度组（平均1.35分），两组差异显著（t(19.501)=-3.174, P < 0.01, Cohen’s d = -1.315）。

EEG指标变化印证干预有效性

通过对前额叶EEG信号的分析，研究团队发现了与晕船缓解相关的典型神经电生理特征：

总频段功率降低：RMS阶段参与者的1-40Hz全频段功率，显著低于RS组和PMS组（聚类置换检验，每个频点P < 0.001）。这一变化与晕船状态下大脑因感官冲突导致的过度激活相反，提示BCI干预可减轻大脑的异常神经活动。

特征频段功率改变：RMS阶段的theta相对功率（4-8Hz）显著低于RS组（t(42)=-2.504, P < 0.05, Cohen’s d = -0.382）和PMS组（t(42)=-2.377, P < 0.05, Cohen’s d = -0.362），而beta相对功率（13-30Hz）显著高于RS组（t(42)=2.772, P < 0.05, Cohen’s d = 0.423）和PMS组（t(42)=3.383, P < 0.01, Cohen’s d = 0.516）。theta波与困倦、不适感相关，beta波则与注意力集中密切关联，两者的反向变化进一步佐证了干预的有效性。

theta/beta比值下降：该比值是公认的注意力评估指标，RMS阶段显著低于RS组（t(42)=-2.876, P < 0.01, Cohen’s d = -0.439）和PMS组（t(42)=-3.386, P < 0.01, Cohen’s d = -0.516），证明BCI能够帮助参与者维持稳定的注意力状态。

结论与展望

传统注意力转移方法在海洋环境中易受干扰，而本研究中的BCI系统通过实时神经反馈解决了这一难题。该系统由单通道EEG头带、计算终端和视听反馈软件组成，可实时采集脑电信号，通过卷积神经网络（CNN）计算注意力分数，并将分数转化为动态视听场景。参与者通过专注于呼吸计数等正念任务提升注意力分数，视听反馈则帮助他们实时监测自身状态，及时纠正注意力分散。

从感官冲突理论视角，研究团队阐释了作用机制：晕船源于视觉、前庭觉与本体感觉的信息冲突。BCI系统从内外两个途径缓解这一冲突——外部通过提供与注意力状态同步的和谐视听刺激，部分遮蔽船舶摇摆与视觉稳定舱室之间的冲突；内部通过增强自上而下的认知控制，帮助用户将注意力从被动的感官冲突信息转向主动的正念专注。神经认知模型中，自下而上与自上而下的加工机制存在竞争关系，BCI引导的主动注意分配可减少对感官冲突信息的感知，从而缓解症状。

这项发表于《IEEE Transactions on Artificial Intelligence》的研究，首次将脑机接口技术成功应用于真实海洋环境中的晕船干预。其核心结论包括：第一，BCI介导的注意力转移是有效的晕船干预手段，81.39%的有效率及EEG指标的显著变化证实，该方案可在真实海洋环境中缓解晕船症状，且对重度患者效果更优；第二，神经反馈是注意力稳定维持的关键，BCI通过实时视听反馈，帮助参与者克服海洋环境干扰，实现从”被动承受”到”主动调节”的注意力转移，打破了传统方法的局限性；第三，无创便携的非药物方案具备广泛应用潜力，该BCI系统体积小、操作简便，无需专业医疗人员协助，解决了药物治疗的副作用与场景限制问题。

未来研究将朝三个方向深入：结合加速度传感器等多模态数据，提升神经活动监测的全面性与准确性；开展纵向研究，探索BCI干预长期应用对晕船易感人群的适应训练效果；拓展应用场景，将该方案推广至晕机等其他类型的晕动病症干预中，助力交通、军事、旅游等多领域发展。

对亿万海上出行人群和海事作业人员而言，这意味着一种无副作用、即时起效、便携易用的解决方案已触手可及。对脑机接口领域而言，这项工作拓展了技术应用的新边界——从医疗康复走向远洋作业，从实验室走向科考船只。未来，”防晕船头环”或许将成为船员和海军人员的标配装备，让每一次远洋航行都从容自在。
