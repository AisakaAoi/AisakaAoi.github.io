IEEE TBME | SleepConFormer：一种用于意识障碍患者睡眠分期与意识评估的单通道脑电框架

发表于 2026-07-13 分类于 🌙进阶学习 ， ⭐SCNU BCI团队 ， 💫学习报告 阅读次数： Valine：
本文字数： 2.6k 阅读时长 ≈ 7 分钟

该论文被脑机接口领域权威期刊 IEEE Transactions on Biomedical Engineering (TBME) 接收，题目为《SleepConFormer: A Single-Channel EEG Framework for Sleep Staging and Consciousness Assessment in Patients with Disorders of Consciousness》。

华南理工大学李曼博士为本文第一作者，华南师范大学潘家辉教授、广东省工伤康复医院何艳斌主任与华南理工大学李远清教授为通讯作者。

论文链接

https://doi.org/10.1109/TBME.2026.3708665

论文概要

意识障碍患者（disorders of consciousness, DOC）的临床评估长期依赖行为反应。然而，运动功能受损、觉醒水平波动以及认知运动分离等因素，可能导致患者残余意识被低估。该论文面向这一临床难题，提出了一种基于单通道 EEG 的睡眠分期与意识评估框架 SleepConFormer，尝试从睡眠脑电中提取与残余意识相关的神经生理信息。

SleepConFormer 通过公共睡眠数据集预训练学习可迁移的睡眠 EEG 表征，再结合面向病理 EEG 的时序建模与阶段混淆估计，实现 DOC 患者粗粒度睡眠状态识别。进一步地，该方法融合睡眠结构信息与多层 EEG 表征，构建个体水平特征，用于区分最小意识状态（MCS）与无反应觉醒综合征（UWS）。

图1 论文总体框架图，展示 SleepConFormer 的睡眠分期模块与意识评估模块。

研究背景

DOC 患者的意识状态评估是神经康复和重症医学中的重要问题。传统床旁行为量表虽然具有临床价值，但在患者无法稳定产生运动反应时，行为评估可能无法充分反映残余意识水平。因此，发展不依赖患者主动配合的客观神经生理评估方法具有重要意义。

睡眠 EEG 为理解意识状态提供了天然窗口。睡眠-觉醒转换反映了脑干、丘脑、下丘脑与皮层网络的动态调控，其宏观结构和微观 EEG 特征可能与 DOC 患者残余脑功能密切相关。与多通道 PSG 相比，单通道 EEG 更适合床旁部署、长期监测和临床转化。

方法

该论文提出的 SleepConFormer 包括两个核心部分：睡眠分期模块和睡眠信息化意识评估模块。睡眠分期模块首先在公共睡眠数据集上进行多任务 EEG 表征学习，利用五分类睡眠分期任务以及与觉醒、意识维度相关的辅助任务，学习具有可迁移性的睡眠脑电表征。

在时序建模方面，论文引入 SCE-Transformer，将 Transformer 的连续片段建模能力与阶段混淆估计机制结合，以适应 DOC 患者睡眠结构破坏、阶段边界模糊和 EEG 异质性强等特点。随后，模型通过 logit 空间聚合策略，将五分类睡眠输出映射为 Wake-Sleep 和 Wake-NREM-REM 等更稳定的粗粒度状态。

在意识评估阶段，模型将预测得到的睡眠结构特征与多层 EEG 嵌入表示融合，形成个体水平的睡眠相关表征，并在严格的留一受试者交叉验证（LOSO-CV）下完成 MCS/UWS 判别。

图2 睡眠分期模型结构图，展示 MTERL backbone 与 SCE-Transformer。

实验结果

论文首先在 Sleep-EDF-2013、Sleep-EDF-2018 和 SHHS 三个公共睡眠数据集上验证模型的睡眠分期能力。结果显示，SleepConFormer 在三组数据集上取得了稳定表现，五分类睡眠分期准确率达到 84.5%–87.7%，跨数据集迁移实验的平均 MF1 达到 78.73%，表明模型具有较好的跨数据集泛化能力。

  • 在 Sleep-EDF-2013、Sleep-EDF-2018 和 SHHS 上，模型分别取得稳定的五分类睡眠分期性能。
  • 跨数据集迁移实验显示，预训练表征能够适应不同采集设备、受试群体和评分协议带来的分布差异。
  • 混淆矩阵显示，模型对 Wake、N2、N3 和 REM 等主要阶段具有较好的区分能力，主要混淆集中在 N1/N2 等过渡阶段。

公共睡眠数据集展示 Sleep-EDF-2013、Sleep-EDF-2018 和 SHHS 的分期结果。

跨数据集迁移实验结果。模型在不同公共睡眠数据集之间迁移后仍保持稳定表现。

在临床 DOC 队列中，该方法用于粗粒度 Wake-Sleep 分期时，整体准确率达到 80.78%，加权 F1 值达到 80.50%。其中，MCS 患者的睡眠分期表现优于 UWS 患者，提示更稳定的睡眠-觉醒结构可能与更高水平的残余意识相关。

进一步地，基于睡眠结构与 EEG 表征构建的个体水平特征，在 MCS 与 UWS 区分任务中取得了 91.7% 的准确率和 0.846 的 AUC。结果表明，睡眠结构与深层 EEG 表征能够提供互补信息，有助于提升 DOC 患者意识状态的自动判别能力。

DOC 队列中个体级粗粒度睡眠分期结果。Wake-Sleep 与 Wake-NREM-REM 两种设置展示了不同患者的睡眠结构差异。

DOC 队列中的分组结果与意识状态判别结果，MCS/UWS 判别达到 91.7% 准确率和 0.846 AUC。

消融实验

论文进一步通过消融实验验证了各核心模块的贡献。结果显示，多任务监督能够提升睡眠表征质量，Transformer 时序建模显著改善模型对连续睡眠结构的捕捉能力，而阶段混淆估计机制进一步增强了模型在过渡阶段和病理 EEG 条件下的鲁棒性。

多任务监督消融实验。引入觉醒和意识相关辅助任务能够提升睡眠 EEG 表征质量。

时序建模与阶段混淆估计消融实验。Transformer 时序建模显著提升模型性能，SCE 模块进一步增强对过渡阶段和阶段混淆的处理能力。

研究意义

该论文表明，单通道 EEG 中的睡眠结构和深层表征可能携带与 DOC 患者残余意识相关的重要信息。相比依赖患者主动配合的任务范式，睡眠 EEG 更适合在临床床旁环境中开展长期、低负担、可重复的监测。SleepConFormer 为意识障碍患者的客观评估、康复监测和预后研究提供了新的深度学习框架。

结论

该论文提出了 SleepConFormer，一种面向 DOC 患者的单通道 EEG 睡眠分期与意识评估框架。通过可迁移 EEG 表征学习、混淆感知时序建模和睡眠信息化个体表征融合，该方法在公共睡眠数据集和临床 DOC 队列中均展现出良好性能。该研究为从睡眠脑电中探索残余意识线索提供了新的方法基础，也为未来床旁监测和纵向预后评估提供了重要参考。
