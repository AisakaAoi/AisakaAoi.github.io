从注意力机制到脑电解码：Transformer 的 EEG 特征学习

之后的文章将回归到我们的主线深度学习当中，今后将会持续分享BCI领域的模型与大模型，另外还想开一个新专栏总结生理信号相关的总结，感兴趣朋友可以进行留言。

如今提到 Transformer，许多人首先想到的是大模型。但 Transformer 并不是从“大模型”三个字里长出来的。它起初要解决的是一个朴素的问题：面对一长串信息，模型怎样找到此刻最该参考的部分，并把远处的内容联系起来？

前一篇文章里，CNN 帮我们理解了模型如何从局部波形中学习特征。这一次先不急着看脑电网络的结构图。我们会从序列模型的发展说起，弄清注意力机制与 Transformer 的关系，再问连续 EEG 怎样进入这样的网络。沿着这条线走到后半篇，EEG Conformer 的卷积前端、自注意力和分类头就不再是几个需要硬背的名字；最后也会沿着同样的思路，分享本人在 2024 年开展的 CT-MIFNet 研究。

一、Transformer 的发展脉络

Transformer 最早不是为脑电设计的。它来自机器翻译等序列任务：模型读入一句话，再生成另一种语言的句子。早期常见的编码器—解码器结构使用循环神经网络（RNN）依次读取输入。这样的方式能处理顺序，但序列很长时，每一步都依赖前一步，难以在同一层把各位置完全并行计算。更早的固定向量编码方式还要求把整句内容压缩成一个向量，解码器要用它生成完整译文，长句中的细节容易成为瓶颈。

2014 年，Bahdanau、Cho 和 Bengio 提出具有代表性的注意力式神经机器翻译方法。它不再要求解码器只依赖那个固定向量：生成每个词时，模型可以重新查看输入句子的不同位置，决定此刻该参考哪一部分。注意力机制先于 Transformer 出现；Transformer 并不是“发明了注意力”。Bahdanau 等原论文

2017 年，Vaswani 等人提出《Attention Is All You Need》。这篇论文向前走了一步：既然注意力可以让一个位置参考其他位置，能不能让它成为整套序列模型的主干？于是，多头自注意力与逐位置前馈网络组成新的编码器—解码器，循环计算不再承担主要的序列建模工作。同一层里的多个位置可以并行处理；不过，模型也必须另想办法表示先后次序，所以原始 Transformer 在输入中加入位置编码。Transformer 原论文

把两代方法放在一句翻译任务中，会更容易理解这一步的意义。假如输入句子的第一个词与最后一个词有关，循环网络需要顺着中间步骤逐次传递状态；注意力允许表示第一个词的位置直接参考最后一个词。原始 Transformer 的编码器让源句中的各位置相互读取；解码器在生成目标词时，既参考已经生成的词，也通过交叉注意力读取编码器输出。由于解码器不能偷看尚未生成的目标词，还要给那一侧的自注意力加因果掩码。后来用于 EEG 分类的网络通常只借用编码器思想：整段已采集的波形可以一起分析，无须照搬逐词生成的解码器。

这里的“并行”也有边界。Transformer 允许同一层各位置一起计算，训练时不必像循环网络那样逐位置等待；但位置两两比较会形成平方大小的注意力矩阵。输入序列越长，显存和计算负担越明显。这个利弊关系后来直接影响了脑电模型怎样切分时间窗、怎样压缩采样点。

后来，Transformer 的处理对象逐渐不限于文字。Vision Transformer（ViT）把图像切成 patch，再把 patch 序列交给 Transformer。它说明：只要能合理构造一串向量，注意力就有机会处理文字之外的数据。当然，图像 patch 与句子里的词并不是同一种东西；后面看到脑电 token 时，我们也要先问它从哪段信号而来。ViT 原论文

这条发展线索有一个容易混淆的地方：注意力机制是一种选择并汇集信息的运算；Transformer 是把多头注意力、前馈网络、残差、归一化和位置信息组织起来的架构。 只是在某个网络后面接一层注意力，还不能据此说明它采用了原始 Transformer 的全部设计。接下来先把最核心的注意力计算讲清，再回来看这些模块怎样连成完整网络。

二、注意力机制：位置关联与信息汇集

读一段较长的文字时，我们不会在理解每个词时都平均回想前面所有词，而会根据当前的问题寻找有用的上下文。注意力机制把这种“依据当前需要去参考其他位置”的过程写成可训练的计算。先把输入想成一排向量 $Z=[z_1,z_2,\ldots,z_N]$ ：每个向量是一个位置的表示，模型希望在保留自身信息的同时，从其他位置取回相关内容。

  • Query 表示当前这个位置提出的查询；
  • Key 用来衡量其他位置与该查询有多匹配；
  • Value 是匹配后真正被加权汇入的信息。

Query、Key 和 Value 是计算中的三个角色，并不是输入原本就有的三个标签。网络通常让同一组输入分别乘以不同的可学习权重矩阵：

如果输入有 $N$ 个位置，单头的 Q、K 可以看作两个大小为 $N\times d_k$ 的矩阵。 $QK^{\mathsf T}$ 因此得到一个 $N\times N$ 的分数表：第 $i$ 行、第 $j$ 列表示“第 $i$ 个位置要在多大程度上参考第 $j$ 个位置”。这些还只是未经归一化的匹配分数。分数除以 $\sqrt{d_k}$ 后经过 Softmax，变成每行和为 1 的权重，再用权重汇集 Value：

图 2｜从同一输入投影出 Q、K、V：Q 与 K 形成位置分数表，逐行缩放、归一化后再汇集 V。下方的三位置数字只演示权重计算。

比如第一个位置对三个输入的权重是 $[0.1,0.7,0.2]$ ，它得到的新向量就可理解为 $0.1v_1+0.7v_2+0.2v_3$ ，其中第二个 Value 的影响最大。注意，“影响最大”说的是这次网络计算，不是第二个位置在现实中造成了第一个位置的变化。换一条输入，Q、K、V 都会改变，权重也会跟着变；这正是注意力能按输入调整信息混合方式的原因。

沿着这个小例子再往前走一步：假设缩放后的三项分数是 $[0,\ln 7,\ln 2]$ ，Softmax 会先把它们变成正数 $[1,7,2]$ ，再除以总和 10，于是得到 $[0.1,0.7,0.2]$ 。这说明权重是同一行各候选位置相互竞争的结果；把第二项分数抬高，另外两项的占比就会下降。Softmax 之后的权重之和为 1，但 Value 可以是有正有负的多维向量，所以输出并非“三个位置的概率”，而是三个向量的加权组合。

从形状上看，若 $V\in\mathbb{R}^{N\times d_v}$ ，那么 $A\in\mathbb{R}^{N\times N}$ 与它相乘，输出 $O\in\mathbb{R}^{N\times d_v}$ 。第一维仍是 $N$ ：注意力更新了每个位置所携带的内容，却没有自动把 $N$ 个位置压成一个分类结果。后续若要给整段 EEG 判类别，仍需池化、展平或专门的汇总 token 等步骤。

实际训练还要带上批量维。若输入为 $Z\in\mathbb{R}^{B\times N\times E}$ ，一头的 $Q,K\in\mathbb{R}^{B\times N\times d_k}$ 、 $V\in\mathbb{R}^{B\times N\times d_v}$ ；分数表是 $[B,N,N]$ ，输出是 $[B,N,d_v]$ 。这里的第二个 $N$ 来自“每个查询位置都与全部键位置比较”，不是电极数自动被复制了一遍。读网络结构时先标出每条轴，再判断模型到底在比较时间片段、电极，还是特征通道。

上式是自注意力：Q、K、V 都由同一条输入序列生成，因此每个位置在更新时都可以参考这条序列中的其他位置。如果 Query 来自一条序列，而 Key、Value 来自另一条序列，就是交叉注意力；早期机器翻译中“生成译文时回看原句”更接近后一种情形。原始 Transformer 的编码器使用自注意力，解码器还使用面向编码器输出的交叉注意力。后文的分类任务主要借用编码器式结构，不需要把翻译用的完整解码器搬过来。Transformer 原论文

缩放点积注意力与多头机制

若 Key 和 Query 的维度较大，点积的量级也可能变大。Softmax 一旦把绝大部分权重压到极少数位置，训练就可能不够稳定。原始 Transformer 采用除以 $\sqrt{d_k}$ 的缩放点积注意力；这里的 $d_k$ 是每个头中 Key 的维数，不是输入序列长度，也不是头的数量。

直觉上，若各维的数值尺度相近、互不强相关，维度越多，点积的典型波动就越大；除以 $\sqrt{d_k}$ 能让分数的尺度不至于随维数明显膨胀。这是设计缩放因子的一个解释，而不是保证任何数据分布下权重都恰好均匀。若还需要屏蔽填充位置或未来位置，通常是在 Softmax 之前把对应分数设成很小的值，使其归一化权重接近零。

只算一张注意力矩阵，相当于让所有关系都在同一种表示空间里竞争。多头注意力会把输入投影到多个子空间，各头分别计算，再拼接并投影回模型维度。假设模型维度是 40，使用 10 个头，常见设计中每头处理 4 维；每个头都能产生一张自己的 $N\times N$ 矩阵。这样模型有机会同时学习不同的信息关系，但“有机会”不代表每个头都能对应一个稳定、可命名的概念。头数增加也不必然提高性能。

把 $H$ 个头一起写出， $Q,K,V$ 通常整理为 $[B,H,N,d]$ ，每头分别算出 $[B,N,N]$ 的权重，再将 $H$ 份 $[B,N,d]$ 输出拼接成 $[B,N,Hd]$ ，最后经线性投影回 $[B,N,E]$ 。当 $Hd=E$ 时，投影前后的特征宽度可以相同，但头之间使用的参数并不相同。若显式保存注意力分数，仅分数张量就有 $BHN^2$ 个元素；计算 $QK^{\mathsf T}$ 及权重乘 $V$ 的主要乘法量级为 $O(BHN^2d)$ 。这只是注意力核心部分的量级，不包括卷积、线性投影与分类头；实际框架使用融合算子时，峰值显存也未必等于“分数元素数 × 数据类型字节数”。Transformer 原论文

三、注意力之外：Transformer 的完整结构

讲完注意力，还不能马上把它当成完整的 Transformer。原始论文的结构分为编码器和解码器：编码器读入整个源序列，解码器逐步生成目标序列，并通过交叉注意力参考编码器输出。许多分类任务只需要读懂已有输入、最后输出一个类别，通常借用编码器这一侧。因此，后文会反复提到“Transformer 编码块”，而不会出现逐词生成译文的流程。

一个常见编码块包括多头自注意力、逐位置前馈网络、残差连接、归一化和 Dropout。注意力在位置之间交换信息；前馈网络对每个位置的特征做非线性变换。可以把前馈网络理解成对每个位置分别应用同一套小型神经网络：先扩展特征维，再通过激活函数，最后投影回原维度。它不会在这一步重新比较不同位置。若输入是 [B,N,E]，只要不改变 token 数和模型维度，一个编码块的输出仍是 [B,N,E]，因此多个块可以接连堆叠。

逐位置前馈网络可以明确写成 $\operatorname{FFN}(z_i)=W_2\sigma(W_1z_i+b_1)+b_2$ ，其中 $W_1$ 把第 $i$ 个 token 从 $E$ 维扩展到 $E_{\mathrm{ff}}$ 维， $W_2$ 再压回 $E$ 维。所有位置共用同一组 $W_1,W_2$ ；它虽对每个位置分别计算，却会学习特征维之间的非线性组合。这样，“注意力跨位置交换、FFN 在位置内部加工”就不只是一个比喻，而能直接从矩阵乘法中读出来。

残差连接可以写成 $Z+F(Z)$ ：子层学到的变化加回原始输入，信息和梯度便有一条较直接的通路。Layer Normalization 调整每个位置上的特征尺度，帮助较深的网络训练。不同实现可能把 LayerNorm 放在注意力或前馈网络之前，也可能放在之后；这些顺序不会改变“哪些模块存在”，却会改变实际计算过程，所以读论文或代码时值得核对。

以“先归一化”的编码块为例，可以把两步写成 $U=Z+\operatorname{MHA}(\operatorname{LN}(Z))$ ，再写成 $Y=U+\operatorname{FFN}(\operatorname{LN}(U))$ 。第一步在不同 token 之间传递信息，第二步在每个 token 内部变换特征。假设输入有 61 个时间 token、每个 40 维，FFN 暂时把特征扩展到 160 维再压回 40 维，输出仍是 61 个 40 维向量。所谓“编码块堆叠六次”，就是让这样的信息交换与特征加工反复进行，而不是把六段 EEG 拼在一起。

图 4｜编码块的两次残差计算。第一步在 token 间交换信息，第二步在每个 token 内变换特征；输出保留原来的序列长度和特征宽度。

还有顺序问题。把“先出发，再到站”和“先到站，再出发”颠倒，含义显然不同；但单独的自注意力若只接收一组向量，没有额外的位置信息，它并不能仅凭向量本身知道谁在前、谁在后。原始 Transformer 在输入表示里加入位置编码，让不同位置带上可区分的标记。论文使用的正弦、余弦位置编码，其核心不是让模型记住某个固定句长，而是给每个位置提供有规律变化的数值表示。后来也有可学习的位置向量、相对位置偏置等方法。有没有显式位置编码，应看具体模型；不能因为名字里有 Transformer 就默认一定使用同一种位置方案。

正弦位置编码可写作 $PE(pos,2i)=\sin(pos/10000^{2i/E})$ ， $PE(pos,2i+1)=\cos(pos/10000^{2i/E})$ 。这里 $pos$ 是 token 在序列里的编号， $i$ 选取不同的特征维。不同维度变化快慢不同，于是相邻位置与较远位置都有可利用的模式。它直接提供的是随绝对位置编号变化的规律表示，模型可以据此学习位置关系；它不是把“0.4 秒”这样的物理时间直接写进模型。如果采样率、池化步长或窗口定义变化，相同的位置编号可能对应不同的实际时间。

最后要分清“看完整段输入”和“预测尚未发生的未来”。普通双向自注意力允许一个位置参考当前窗口内的所有位置，适合已收齐整段数据后的分析；逐步生成或严格实时输出时，则需要因果掩码，或明确接受等待后续数据带来的延迟。 $N$ 个 token 的普通全局自注意力还会形成 $N\times N$ 的分数矩阵，token 越多，计算和存储成本增长越快。这些问题并非 EEG 特有，但一旦处理高采样率的连续波形，就会格外具体：到底怎样划分输入，才能既留住信息，又让计算可承受？

四、Transformer 进入 EEG：连续波形的序列化

现在再回到 EEG。它和句子最大的不同，是没有现成的“词”。电极连续记录电位变化，一段信号既有时间轴，也有电极轴，还夹杂着眼动、肌电和采集噪声。如果不先说清一个 token 代表什么，那么“模型让 token 彼此注意”就只是听起来很先进的一句话。

假设输入是一段 4 秒 EEG，包含 22 个电极，以 250 Hz 采样。单个试次可写成 $X\in\mathbb{R}^{22\times1000}$ 。上一文的 CNN 可以在这个矩阵上寻找局部振荡、幅值变化和跨电极组合。如果这次任务还希望比较窗口开头与结尾的模式，单层短卷积无法让两处直接交换信息；自注意力提供了另一条路径。

CNN 当然也能通过堆叠卷积、增大卷积核或使用空洞卷积扩大感受野。这里并不是要把它和 Transformer 分成“只能看近处”与“只能看远处”两派。更准确的区别是：卷积通常通过局部连接逐层整合信息；自注意力则让一个位置直接对同一输入中的其他位置计算权重。如何组合两者，要看任务和数据，而不是先认定哪一种结构更高级。

连续 EEG 的 token 构造方式

在文字任务中，token 可以是词或子词；EEG 没有这样的天然边界。研究者可以把每个采样位置当作 token，也可以先切短时间窗、计算时频表示，或者先让 CNN 提取局部时空特征。几种做法并无统一赢家：它们决定模型更容易看到哪类模式，也决定 token 数量与计算成本。

卷积特征位置经过局部滤波与通道组合后的表示已融入卷积前端的结构假设

假设处理后得到 $N$ 个 token，每个用 $E$ 维向量表示，批量输入可写成 $Z\in\mathbb{R}^{B\times N\times E}$ 。这里的 $N$ 是模型构造出来的序列长度，不一定等于原始采样点数，也不一定等于电极数。如果 token 按时间排列，那么注意力矩阵的行与列都对应时间位置；如果把电极做成 token，矩阵才会沿电极轴展开。即便是后一种设计，注意力权重也只说明模型内部怎样混合信息，不能直接等同于脑区之间的生理连接。

时间窗方案还有一个可核对的计算。对 $T$ 个采样点，用宽度 $W$ 、步长 $S$ 的滑窗且不补零时，窗口数是 $N=\lfloor(T-W)/S\rfloor+1$ 。例如 $T=1000$ 、 $W=100$ 、 $S=50$ ，得到 19 个窗口；在 250 Hz 下，每个窗口覆盖 0.4 秒，相邻窗口起点相隔 0.2 秒，重叠 50 个采样点。19 是这个教学示例的 token 数，EEG Conformer 的卷积、池化会给出另一套数字。窗口重叠越多，时间定位通常越细，后续注意力的序列也越长；采样率改变时，还要重新按秒检查 $W$ 和 $S$ ，不能只照搬点数。

若直接把 1000 个采样位置都作为 token，一头注意力就要形成 $1000\times1000$ 的关联矩阵。先压缩为几十个局部表示能大幅降低这部分成本，但可能丢掉细节。运动想象任务可能希望比较一段时间里的节律变化；若是对事件相关电位的潜伏期敏感，过早的大步长池化就可能带来损失；整夜睡眠分期还涉及片段之间更长尺度的上下文。同一个 Transformer 词汇，到了不同任务里，输入构造却可以很不一样。

仍以 10 头、单个试次为例，1000 个 token 要产生 $10\times1000^2=10{,}000{,}000$ 个分数；若压到 61 个 token，则为 $10\times61^2=37{,}210$ 个，相差约 269 倍。这个比值只比较注意力分数表的元素数，不能直接宣称整网训练速度或总显存也会相差 269 倍。池化减少的计算成本，应和事件时间精度、短暂波形是否被平均掉一同评估。

这里还要分清三个常被并排写出的维度。时间维回答特征何时出现、持续多久；空间维描述不同电极测得的电位怎样组合；频率维描述信号在不同振荡频率上的成分。它们来自同一段波形，并非三个彼此独立的数据源。运动想象中常讨论的感觉运动节律，使时间与频率的组合有意义；刺激后的疼痛脑电则可能更在意响应潜伏期和波形形态。若只给每个 token 一个未经解释的向量，模型能否保留这些信息，就只能靠实验猜。

因此，阅读 EEG Transformer 时可以先画一张“轴的地图”：原始输入的电极轴在哪里？卷积或空间滤波是否把电极组合掉了？频谱是从哪段时间计算出来的？token 按时间、频率还是电极排列？只有回答这些问题，注意力矩阵的两条轴才有明确含义。比如时间 token 的 $N\times N$ 权重不能被直接画成电极连接图；沿特征通道计算的注意力，也不等于发现了脑区之间的因果联系。

一种颇有启发的选择，是沿用 EEG CNN 擅长提取局部波形和电极组合的优点，先把原始信号变成较短的特征序列，再由 Transformer 整合序列关系。读 EEG Transformer 论文时，EEG Conformer 正是一篇值得认真拆解的工作：它没有要求注意力从未经加工的电压点开始“自己发现一切”，而是明确安排了卷积与注意力各自负责的部分。

1. 卷积模块：先让模型读懂局部 EEG

先把输入放在眼前：22 根电极，每根记录 1000 个采样点，若采样率为 250 Hz，就是 4 秒。PyTorch 中再添上 batch 维和初始特征平面维，形状成为 [B,1,22,1000]。其中的 1 容易误读——它不是说 EEG 只有一根电极；真正的电极维是 22。这一点和前一篇 EEGNet 中区分“物理通道”与“网络特征通道”的道理相同。

第一层的时间卷积核大小为 (1,25)：高度为 1，所以先不跨电极；宽度为 25，所以每次观察一个电极上连续的 25 个采样点。在 250 Hz 下，这相当于约 0.1 秒的局部观察窗口。没有 padding 时，时间长度从 1000 变为 $1000-25+1=976$ 。网络学到的核可能对某些波形或节律有用，但核长 25 点并不能直接说明它就是某个固定频带的滤波器。

第二层的空间核大小为 (22,1)，刚好覆盖全部 22 根电极、只跨一个卷积后的时间位置。它把各电极的响应组合起来，电极维于是从 22 压成 1；这个“1”表示形成了新的组合特征，不是只剩下一根电极。随后是 Batch Normalization、ELU、时间平均池化和 Dropout。作者使用 40 个特征通道，池化核为 (1,75)、时间步长为 15。论文 Table I 与方法部分、作者实现

卷积的运算也能落到一个采样位置上看。忽略偏置和激活，第 $f$ 个时间特征在电极 $c$ 、位置 $t$ 的值是 $h_{f,c,t}=\sum_{\tau=0}^{24}w_{f,\tau}X_{c,t+\tau}$ 。同一组时间核沿时间滑动，也用于不同电极，因此 40 个长度为 25 的核只有 $40\times25=1000$ 个卷积权重；输入有 22 根电极，并不意味着这组权重再乘 22。

空间层则可写成 $s_{g,t}=\sum_{f=1}^{40}\sum_{c=1}^{22}u_{g,f,c}h_{f,c,t}$ 。它同时汇集电极轴与前一层学出的特征轴，不是简单对 22 根电极求平均。空间核的时间宽度为 1，所以这一层不再扩大时间感受野；后面的时间池化才汇总邻近时间响应。EEG Conformer 作者实现

2. 自注意力模块：比较 61 个时间 token

卷积前端完成了局部信息提取，下一步才轮到 Transformer。输入形状为 [B,61,40]：61 个位置沿时间排列，每个位置是一条 40 维的摘要。第 $i$ 个 token 可以用第二章的 Q/K/V 机制参考同一输入窗口中的其他 token。卷积把相邻波形加工成局部特征，注意力让这些局部特征跨时间交换信息，二者在这里各有任务。

把形状展开也不难：[B,61,40] 使用 10 个头时，每个头的 Q、K、V 可看作 [B,10,61,4] 中属于它的一份；一个头产生一张 61×61 的时间关联矩阵。各头结果拼接并投影，输出又回到 [B,61,40]。变化的是每个 token 携带的内容，token 数量没有因此减少。 比如窗口开头与结尾两个位置可以直接计算关联，但注意力并不预设“远处一定重要”；有的输入可能主要依赖相邻位置。

作者将编码块重复 6 次，默认使用 10 个头。每块先经过“LayerNorm → 多头注意力 → Dropout → 残差相加”，再经过“LayerNorm → 前馈网络 → Dropout → 残差相加”；前馈网络将 40 维暂时扩展到 160 维，最后再压回 40 维。第三章的通用结构到这里便落到了具体数字上。作者代码中的 TransformerEncoderBlock

每个块都保持 [B,61,40]，读表时可能感觉“形状没变，是不是没做事”。其实 token 内容已经被重新计算：注意力从其他位置取回信息，前馈网络再加工每个位置的特征。形状相同，只是为了让下一块继续处理同一条序列。

这里说的“全局”，边界是当前 4 秒输入窗口内的 61 个 token。模型不会自动读到前一分钟的脑电；若任务需要更长的上下文，还得改变输入窗口或增加跨窗口结构。普通自注意力的关联矩阵又随 token 数约按 $N^2$ 增长，所以简单把窗口拉得很长、把池化步长压得很小，计算成本也会随之上升。

还要记得，结构允许远距离交互，与模型真的学到了有用的长时关系，是两回事。模型究竟依赖了什么，要看实际权重、对照实验以及独立测试，而不是只看那张从左到右连得很漂亮的架构图。

有一个容易在复现时忽略的细节：第二章介绍的标准缩放注意力使用 $\sqrt{d_k}$ ，这里每头 $d_k=4$ ；作者公开代码则以 $\sqrt{E}$ 缩放，这里 $E=40$ 。两种实现的注意力分数尺度不同。后文的 PyTorch 教学代码采用标准模块，重点是帮助读者追踪结构与形状，并非作者代码的逐行复刻。EEG Conformer 作者实现

3. 分类头：固定形状的来源

六层编码器走完，我们仍然握着 61 个 40 维向量，而分类器最终需要给整段试次一个标签。作者在 BCI Competition IV 2a 的代码中把它们展平为 [B,2440]，随后通过全连接层输出 4 个运动想象类别的分数。这里的 2440 来自 $61\times40$ ，4 来自任务类别数；它们都不是可以无条件搬到其他 EEG 数据集上的神奇常数。作者代码的 ClassificationHead

把输入时间点数改成 500 就能看出影响：25 点无填充卷积后剩 476 个位置，池化后为 $\lfloor(476-75)/15\rfloor+1=27$ 个 token，展平维度变成 $27\times40=1080$ 。如果还把它送进写死为 2440 维输入的全连接层，程序会在这里报错。换电极数时，前面的 (22,1) 空间核也要调整；换类别数时，最后一层同样要改。

固定展平还有一个值得想一想的代价。原代码第一层全连接做 2440 → 256，仅权重就有 $2440\times256=624{,}640$ 个。它保留了不同 token 在展平向量中的位置，但也让分类头依赖固定 token 数，并贡献了不少参数。因此，论文说卷积加注意力的主干较紧凑，不应被误读为整套实现里的每个部分都极小。

当然也能把 61 个 token 做全局平均，再用一个较小分类层。这样对输入长度更灵活，却会改变模型保留时间位置的方式：平均之后，“某种响应在前半段出现”与“它在后半段出现”可能更难区分。选哪种分类头应服务于任务；只要换了，就要诚实地称它为修改后的模型，而不是说自己完整复现了原始实现。

4. 位置编码与 EEG Conformer 的时间顺序

前面说过，自注意力自身并不知道位置先后，读到这里可能会追问：“这篇论文的位置编码在哪里？”看作者公开代码会发现，PatchEmbedding 没有再给 token 加一组显式的正弦或可学习位置向量。输入先经过时间卷积，池化结果按时间顺序排成序列，最后又被有序地展平给分类头。作者代码中的 PatchEmbedding

因此要分开看：单独的自注意力层没有显式位置编码，就不能仅凭 token 下标判断先后；整个网络仍通过卷积生成的局部结构和位置敏感的展平分类头利用了时间顺序。 这不是“完全没有顺序信息”，也不是“注意力天然知道相距多少秒”。如果想检验显式位置编码是否有帮助，最可靠的方法是在同一数据划分下做消融实验。

CT-MIFNet 研究：多视角 EEG 信息融合

读到这里，EEG Conformer 的主线已经清楚了：卷积把波形压成一串局部时空特征，注意力再联系不同时间位置。目前领域的传统EEG Transformer架构只关心时空域的特征，并没有用到频域相关的信息，所以我们希望把同一段 EEG 的时间变化、频率成分和电极间差异都用得更充分。它们并非三份独立信号，而是从不同角度观察同一段脑电。若先把所有信息挤进一条特征流，模型虽仍有机会学习到它们，却未必能明确建立不同视角之间的联系。

另一个现实约束来自序列长度。短窗口、较低采样率的 EEG，普通注意力尚能承受；高采样率或较长时间窗会带来更多 token，跨分支逐一比较 token 的显存开销也会快速增长。CT-MIFNet 因而同时处理两个问题：保留多视角信息的互补性，并降低跨视角交互这一步的长序列负担。理解这两个目标，后面的 Multi-CSP、双分支卷积和 CCA 就能连成一条思路，而不是一串彼此孤立的模块名。

围绕这两个问题，为大家介绍一下我们在2024年展开的工作，我们提出了 CT-MIFNet， Convolutional Transformer-based Multi-view Interaction and Fusion Network for EEG Decoding。CT-MIFNet 论文、公开代码

它不是把 EEG Conformer 的编码器简单加深，而是沿着“空间整理 → 时域和频域两条分支 → 分支内部建模 → 分支之间交互与融合 → 分类”重新安排数据流。图 12 参照原论文 Figure 1 重绘，便于把各模块放到一条线上；图中展示的是论文方法，公开代码的若干实现差异将在对应段落说明。

1. 空间变换与时频双分支

模型先对原始信号滤波和标准化，再做多类共同空间模式（Multi-CSP）变换。CSP 原本擅长处理二分类运动想象：它寻找一些电极的线性组合，使两类试次在这些组合上的方差尽量有区分度。这里的“空间”指电极之间怎样加权组合，不是把二维头皮图像送进卷积网络。模型拿到的仍是一条条随时间变化的信号，只是每条信号不再与某一根原始电极一一对应。

这一步有两层含义。滤波先限制网络要处理的频率范围，标准化再减小数值尺度差异；二者只是把输入整理得更稳定，不能替模型决定哪些脑电模式与任务有关。Multi-CSP 则加入更明确的任务先验：不同类别在某些电极组合上的信号方差可能不同。以左右手运动想象为例，感觉运动区的节律变化常为这个想法提供依据，但 CSP 学到的只是统计上有区分度的电极权重，不能直接当作脑源位置或临床诊断。

多分类时，论文采用“一类对其余类”（one-versus-rest）策略：四类运动想象可变成四个二分类问题，分别学习空间滤波器，再把选出的滤波器堆叠起来。若标准化后的试次为 $X_z\in\mathbb{R}^{C\times T}$ ，空间滤波矩阵为 $F\in\mathbb{R}^{\lambda\times C}$ ，输出便是 $Z=FX_z\in\mathbb{R}^{\lambda\times T}$ 。 $C$ 是电极数， $T$ 是时间采样点数， $\lambda$ 是保留下来的空间成分数。这个矩阵乘法压缩了电极维，却没有抹掉时间轴，后续网络仍能读取波形变化。

再往细处看，CSP 要先根据训练试次估计各类的协方差，寻找使“一类”与“其余类”方差对比明显的投影方向。假设四分类中每个一对其余任务保留 $a$ 条空间滤波器，堆叠后就有 $\lambda=4a$ 条空间成分；这只是解释矩阵形状的例子，实际保留数量应依论文设置与数据而定。这里有一道必须守住的实验边界：空间滤波矩阵 $F$ 依赖类别标签，必须在当前训练集上拟合，再应用到测试集。若把所有试次先一起求 CSP，再划分训练测试，测试标签的信息已经渗入特征构造，后面的分类准确率就失去了独立检验的意义。

CSP 的判别准则可以再具体一步。对训练试次 $X_i$ ，常见做法先计算按迹归一化的协方差 $R_i=X_iX_i^{\mathsf T}/\operatorname{tr}(X_iX_i^{\mathsf T})$ ，再对“一类”和“其余类”分别求平均，得到 $\Sigma_c$ 与 $\Sigma_{\neg c}$ 。一个空间方向 $w$ 的目标可写成最大化 $w^{\mathsf T}\Sigma_cw/[w^{\mathsf T}(\Sigma_c+\Sigma_{\neg c})w]$ ；相应方向由广义特征值问题求出。取特征值两端的方向，是为了同时保留对两组方差有区分力的投影。不同 CSP 实现会在协方差估计、正则化和选择方向数上有差别，但它们共有的关键点是： $w$ 由带标签的训练试次估计，不能在测试折上重新拟合。

接下来， $Z$ 直接进入时空分支；同一 $Z$ 经快速傅里叶变换（FFT）得到频域表示，再进入频空分支。两条分支的“空间”来自前面的电极组合及后续空间卷积；“时”与“频”则说明卷积读取的是时域波形还是变换后的频域信息。公开实现对每条空间成分计算 $F_{r,k}=|\operatorname{FFT}_{M}(Z_r)_k|$ ，其中 $M$ 由配置中的 FFT 长度指定；随后截取前后两段频率点并拼接，供频空分支读取。这里保留的是 FFT 幅值，相位被舍弃；功率谱通常涉及幅值平方及相应归一化，不能把两者混写。由于 FFT 长度可以与原试次点数不同，频率分辨率还应按实际 $M$ 与采样率计算；零填充只让频率轴采样更密，不会凭空产生新的信号信息。两条路的目的，是让网络分别学习随时间展开的形态和频率成分，再决定怎样交换信息。CT-MIFNet 公开频域处理代码

2. 多尺度卷积与双分支 token 构造

同一类脑电模式可能持续几十毫秒，也可能延续更长时间。只给卷积一个固定宽度，就等于先替模型限定了观察尺度。CT-MIFNet 在两条分支各设四种卷积核宽度；论文 Table 1 把它们写成约 $0.64f_s$ 、 $0.32f_s$ 、 $0.16f_s$ 和 $0.08f_s$ 个点，其中 $f_s$ 是采样率。以 250 Hz 为例，大致对应 160、80、40、20 个点。这里的数字表示核在各自输入轴上的宽度；时域核的点数可以换算为观察时长，频域核不能直接照搬成秒数，因为 FFT 后横轴的含义已经改变。

四个尺度的卷积结果先拼接，再做跨空间成分的卷积和映射卷积，最后整理成长度为 $L$ 、每个 token 有 $d_m$ 维的序列。时空分支与频空分支因此各得到一组 $L\times d_m$ 特征。可以把这一过程理解成先用多个大小不同的“观察窗”找局部模式，再把观察结果压成供注意力读取的向量。它与直接把每个原始采样点当作 token 不同：进入 Transformer 的已经是经过频率或时间卷积、空间组合的特征。

四种核并行，是这一步区别于单一卷积核的关键。宽核汇集较大范围的变化，窄核保留更局部的起伏；拼接后，后续层有机会按任务学习哪些尺度更有用。空间卷积又跨过前一步的多个空间成分，配合后续网络的非线性变换，在 Multi-CSP 的线性投影之外继续学习更复杂的组合。最后的映射卷积相当于把连续特征整理成 Transformer 可处理的 token 序列。卷积尺度、空间组合和 token 长度是三次不同的设计选择，不能只看最终的 $L\times d_m$ 就把前面的信息加工忽略掉。

按公开实现追踪一条分支，四路时间或频率卷积各输出 4 张特征图，拼接为 16 张；后接跨空间成分的卷积，再由映射卷积以自己的核大小和步长形成 patch。因而每个 token 的信息来源并不是“某个原始点”，而是经历了核宽决定的局部滤波、空间成分组合和 patch 映射。核宽以采样点或频率点为单位，映射卷积的步长则决定相邻 token 隔多远；两者共同影响 $L$ ，也共同影响下游注意力的成本。具体维度仍要随数据集配置核对。CT-MIFNet 公开网络实现

两组 token 随后加入正弦位置编码。这与前述 EEG Conformer 的公开实现形成区别：后者没有加入显式位置编码。两篇工作的前端、后端都不同，具体设计仍需看模型本身，不能只凭“Transformer”这个名称判断。对 CT-MIFNet 而言，位置编码至少让后续注意力有一条区分序列位置的线索；它仍不自动等于物理时间标签，频域分支的位置尤其要结合其 token 化方式解释。

3. 自注意力、CCA 与中位数掩码的跨分支交互

每条分支先经过若干自注意力块，在本分支内部整合特征。然后模型让两条分支互相提供信息：一条分支形成 Query，另一条分支提供 Key、Value，交换方向后再做一次。论文把跨分支交互的核心称为 Cross-Covariance Attention，缩写 CCA。这里的 CCA 不是经典统计学里的“典型相关分析”，也不是前面的 CSP；它指沿特征通道建立关联的注意力计算。

先做分支内自注意力，是让时空 token 与其他时空 token 交换信息，让频空 token 与其他频空 token 交换信息。之后才进入跨分支阶段。这样安排的意思是：各自先形成相对完整的表示，再让时域与频域互相补充。两阶段的“注意力”虽然都使用 Q、K、V，所比较的对象却不同：前者比较同一分支内的位置，后者比较来自不同分支的特征通道。

差别可以用矩阵大小看清。普通跨 token 注意力让 $Q,K\in\mathbb{R}^{L\times d}$ 相乘为 $QK^{\mathsf T}\in\mathbb{R}^{L\times L}$ ，比较“这条分支第几个 token”与“另一条分支第几个 token”。CT-MIFNet 的 CCA 则先把 Q、K 归一化，再形成 $\widehat K^{\mathsf T}\widehat Q\in\mathbb{R}^{d\times d}$ ，比较两条分支的特征通道，最后让 $V$ 与这张通道矩阵相乘。这里的“协方差注意力”是模型模块名称；这张归一化后的通道关系矩阵不能直接等同于统计学中经过中心化计算的样本协方差矩阵。若 $L=1000$ 、 $d=40$ ，前者一头需要 $1000\times1000$ 的分数表，后者是 $40\times40$ 。它并非完全忽略时间：通道相似性仍由整条输入序列的表示计算出来；只是这一步不显式保存每对 token 的权重。

把一头的形状写完整会更清楚：为方便阅读，把来自两条分支的 $Q_A,K_B,V_B$ 记为 $[B,H,L,d]$ ；公开代码实际把头轴排在批量轴之前，但矩阵运算都作用于最后两维。代码先在最后一个特征维上归一化 Q、K，再算 $M=\widehat Q_A^{\mathsf T}\widehat K_B\in\mathbb{R}^{B\times H\times d\times d}$ ；在分数矩阵上做缩放与 Softmax 后，用 $(PV_B^{\mathsf T})^{\mathsf T}$ 得到 $[B,H,L,d]$ 的输出。论文公式写作 $\widehat K^{\mathsf T}\widehat Q$ ，而当前公开代码写作 $\widehat Q^{\mathsf T}\widehat K$ ；矩阵相互转置，后续与 $V$ 的乘法方向也必须一并核对，不能未经检查便视为逐行相同的实现。这里的 $d$ 指每头维度。CT-MIFNet 公开 CCA 实现

图 15｜参照 CT-MIFNet 原论文 Figure 3a–b 重绘：分支内 SA 形成 $L\times L$ 的 token 矩阵，跨分支 CCA 形成 $d\times d$ 的通道矩阵。底部注明论文掩码规则与当前公开代码的差异。

从计算量上说，普通跨 token 注意力的矩阵乘法随 $L^2d$ 增长；通道注意力的相应乘法主要随 $Ld^2$ 增长。当 $L$ 远大于 $d$ 时，后者通常更省这一部分的计算与显存。这并不等于 CT-MIFNet 全网都只有线性复杂度：两条分支里仍有自注意力块，前端卷积与后端融合也要计算。论文在疼痛数据上比较不同采样率的推理显存，观察到 CCA 方案随序列增长的内存压力低于替换成普通跨注意力的方案；这个实验支持的是该模块在所测设置中的优势，不能无条件外推到任何输入长度和硬件。

论文方法还提出在自注意力与 CCA 中使用中位数掩码：对分数矩阵的每一行求中位数，把较弱的匹配在 Softmax 前置为负无穷，让保留项重新分配权重。这是在模型内部筛选匹配，并非原始 EEG 的去伪迹算法，也不保证高分一定代表真实神经信号。论文还写明两条分支的 CCA 块共享参数，以减少模型参数并提取共同特征；当前公开代码却分别实例化两个跨分支模块。因此，参数共享也是复现时需要核对的一处论文描述与仓库版本差异。CT-MIFNet 论文、公开网络实现

可以用一行人为设定的分数看清掩码的次序： $[-0.4,0.1,0.8,1.0]$ 的中位数是 $0.45$ ，前两项低于阈值，在 Softmax 前被屏蔽；后两项再互相竞争得到最终权重。阈值来自当前这一行，不是一套对所有受试者固定的脑电幅值门槛。掩码改变的是注意力的选择范围，不会自动消除眼动或肌电伪迹；它是否改善解码，仍要靠与无掩码版本的对照来判断。

这里有一项复现时必须写明的论文方法与当前公开代码差异。当前仓库的两处注意力实现都调用了非原地的 masked_fill，却没有接住它返回的新张量，随后仍对原分数做 Softmax；按这份源码，掩码并未进入后续计算。若要实现论文描述的规则，应将返回值赋回分数张量，并确保每行至少保留一个有限分数。公开代码还用 torch.median 取阈值、屏蔽小于或等于阈值的项；对偶数个数值，它选出的阈值和上面按常规定义计算的 $0.45$ 可能不同。图 15 展示的是论文方法的运算意图，不能据此断定当前仓库代码已经执行了该掩码；同样，也不能由仓库现状反推论文实验当时使用了同一版本。CT-MIFNet 源码、PyTorch masked_fill 文档

4. 多视角特征融合与分类

两条分支交换信息后，模型不是简单求平均。论文 Table 2 展示了两种拼接：一条沿序列长度方向把两个 $L\times d_m$ 张量接成 $2L\times d_m$ ，另一条沿特征维把它们接成 $L\times2d_m$ ；两者再分别映射回 $L\times d_m$ 。前一种保留了更多特征位置，后一种把同一位置的两路内容并排放到一个向量里。最后的 CCA 融合块继续整合两路信息，分类头使用三层全连接网络输出类别。

只看符号不太直观，可以假设两路各有 60 个 64 维 token。沿 token 维拼接后是 $120\times64$ ，沿特征维拼接后是 $60\times128$ ；再经线性映射回 $60\times64$ ，方便后续融合块读取。这里的 $60$ 和 $64$ 只是演示形状，不是论文三组数据集共同采用的固定超参数。设计两种拼接，是为了同时保留“更多特征位置”和“同一位置上两种视角的并列信息”。不过，拼接本身只把信息放在一起，真正学习它们之间关系的仍是后续映射和 CCA。

训练时论文使用标签平滑，系数为 $0.01$ 。若有 $K$ 类，原本给正确类别的独热标签会改成 $y’_k=(1-\varepsilon)y_k+\varepsilon/K$ ，其中 $\varepsilon=0.01$ 。这让训练目标少一些“正确类必须是绝对的 1、其他类必须是绝对的 0”的要求，有助于缓解过度自信，但效果仍应由实验判断。论文还在训练集内做时间片段切分与重组增强；和前面的 EEG Conformer 一样，任何增强、标准化或 Multi-CSP 拟合都必须限定在训练数据内，否则测试集信息会提前进入模型。

严格复现时还要核对平滑概率分给了谁：上式是论文中的写法，正确类概率为 $1-\varepsilon+\varepsilon/K$ ，其余各类为 $\varepsilon/K$ ；公开 LabelSmoothingLoss 则给正确类 $1-\varepsilon$ ，把 $\varepsilon$ 平均分给其余 $K-1$ 类。两种分布都合法，但数值并不相同。若直接拿公开代码复现实验，应记录采用的是代码公式，并避免把它与论文公式当成完全一致的实现。CT-MIFNet 公开损失函数

论文使用 Adam 优化器，学习率为 $2\times10^{-4}$ 、批量大小为 50，并通过同类别试次的时间片段重组扩充训练输入。这类增强的用意是增加有限 EEG 样本的变化，但它也可能在拼接处制造原始记录里没有的波形边界。报告模型效果时，增强方式和数据划分都应和网络结构一起说明；否则即使模型名字相同，复现出来的结果也可能不是同一项实验。

5. 三组实验的结果与适用边界

论文在两种任务范式上检验这个设计。BCI Competition IV 2a 是九位受试者、22 电极、四类运动想象；按不同日期的两个 session 做训练与测试。2b 也是九位受试者，但只有三路 EEG、左右手两类运动想象，使用前几场 session 训练、后续 session 测试。第三组 EDLEP 数据是激光诱发疼痛脑电，使用刺激后 1 秒的 32 电极信号，区分高、低疼痛条件，并采用五折交叉验证。EDLEP 原始数据有 34 位受试者，论文按表现选取其中九位；这一结果只覆盖所选样本，不能写成 34 人总体上的验证。 三组数据的任务、通道数和验证方式都不同，准确率之间不能直接横向排“难度”或“优劣”。

预处理也随任务改变。2a 取运动想象试次的 2–6 秒、2b 取 3–7 秒，二者以 250 Hz 采样并在实验中做 4–40 Hz 滤波；EDLEP 取刺激后 0–1 秒，采样率为 1000 Hz，实验中使用 30 Hz 低通 FIR 滤波。这些时间窗的选取决定了模型能看到哪段行为或诱发反应。把 2a 的 4 秒窗口和疼痛任务的 1 秒窗口混在一起，只报一个“模型对 EEG 的平均准确率”，既混淆了任务，也掩盖了输入长度对注意力开销的影响。

从单个受试者再看，平均值背后的分布并不整齐。论文在 2a 中报告，受试者 2 和 6 相对 EEG Conformer 有较明显提升；但受试者 3 和 9 并未普遍优于其他 CNN 或卷积 Transformer 方法。2b 中也有某些受试者由别的模型得到更好结果。EDLEP 上 CT-MIFNet 的平均准确率略高于 PainAttnNet，但后者的受试者间标准差更低。这样读结果，更接近模型在不同人身上的真实表现，也提醒我们“平均最好”和“每个人都稳定”是两个不同目标。

消融实验更接近“哪个设计真正起作用”这个问题。去掉多尺度与空间卷积，或去掉 Transformer 交互融合模块，三组数据的表现通常会下降；把多尺度卷积换成单尺度卷积，在 2a 上平均准确率从 81.67% 降为 78.39%。这支持多尺度局部特征的价值。Multi-CSP 的效果则因任务而异：在运动想象数据上有帮助，疼痛数据中去掉它反而可能更好。这一点很重要，因为 CSP 的判别依据与运动想象中的空间节律差异比较契合，却不保证适合所有诱发反应。

消融的解释要与基线比较分开。整网优于某个基线，并不能单独证明 CCA、多尺度卷积或 Multi-CSP 各自必不可少；只有控制其余条件、移除相应模块后观察变化，才更接近模块贡献。论文分别考察了多尺度加空间卷积模块、Multi-CSP、数据增强以及 Transformer 交互融合模块。前两组运动想象任务与疼痛任务对 Multi-CSP 的不同反应，也说明“一个模块在某数据集有益”不能写成“该模块对所有 EEG 解码都有益”。

论文还把疼痛数据中的 CCA 块替换为普通交叉注意力，平均准确率由 83.48% 变为 82.57%；同时，随采样率提高，CCA 方案在实验中的推理显存占用更低。准确率差距本身较小，因此我更愿意把这组结果读成：在这套输入和实现里，通道交互提供了有竞争力的性能，并改善了所测的长序列显存负担，而不是宣称它在任何 EEG 数据上都一定优于普通交叉注意力。

论文的可视化提供了另一种观察角度：t-SNE 将试次的高维特征投到二维，热图比较跨分支交互前后的特征相似性。它们有助于观察类别是否更容易分开、两路表示是否更相关；但二维点云会受降维参数影响，热图变红也不等于发现了大脑真实的传递通路。可视化与消融、独立测试一起看，才比较接近“模型究竟改进了哪里”的答案。

这项工作的核心尝试，是让时间、频率和空间信息先各自形成较清楚的表示，再让它们交换、融合。现有实验还不足以判断模型在未入选的疼痛受试者、从未见过的新使用者及严格在线反馈场景中的表现。频域表示的具体实现、Multi-CSP 的训练折拟合和推理延迟，也都影响复现与应用。把这些边界写清楚，模型才能在下一轮更严格的验证中得到可靠评价。CT-MIFNet 论文与实验表格

九、注意力贡献的实验验证

两篇模型读懂了，下一步不是立刻比较谁的准确率最高，而是先问：这些结果回答的是哪个实验问题？ EEG Conformer 论文包含 BCI Competition IV 2a 的四类运动想象、2b 的两类运动想象和 SEED 的情绪识别实验。2a 的 22 根电极、四分类，与 2b 的三通道、两分类，以及 SEED 的数据采集和标签，差异都很大。相同的网络思想可以用于多种数据，并不意味着一份写死 22 电极、4 类的代码无需调整便能直接通用。EEG Conformer 数据集说明

即使只看运动想象，也要把“跨 session”和“跨受试者”分开。前者是同一个人不同日期的数据能否互相泛化；后者是模型遇到从未见过的人时表现如何。论文在 2a 实验中用第一场 session 训练、第二场 session 测试，这考察的是前一种情况。它比把同一试次的片段随机打散更严格，但不能把得到的性能数字直接称作跨受试者结果。若目标是面向新使用者，训练、验证和测试就应按受试者分开。论文实验协议

划分时机也会改变结论。假如一条试次被切成几个彼此重叠的时间窗，先切窗再随机分训练和测试，两个集合里就可能出现几乎一样的波形。更稳妥的顺序是先按试次、session 或受试者划分，再只在各自集合内生成窗口。标准化所需的跨样本统计量应从训练集估计；测试数据不参与选择滤波范围、池化尺度、头数或停止训练的时机。这样，测试集才能真正代表一次尚未见过的输入。

图 18｜EEG 实验的验证流程。训练侧包括标准化、Multi-CSP 与数据增强的拟合；测试侧只接收锁定后的处理和模型，不能重新选择超参数。

EEG Conformer 论文还采用分段重组增强（segmentation and reconstruction）：从同一类别的训练试次取出片段，再按时间顺序拼接，生成新的训练输入。这是应对 EEG 样本量有限的一种办法，但重组方式本身也会影响时间连续性；如果片段池混入测试试次，更会直接造成泄漏。复现时，增强只应发生在当前训练折内部，并与不使用增强的结果作对照。EEG Conformer 增强方法

在这些基础都固定之后，才轮到问“Transformer 有没有贡献”。一个清楚的消融实验会保持卷积前端、数据划分、训练预算和分类头尽量一致，只移除或替换注意力编码器。还可以分别改变层数、头数和池化窗口，观察性能与参数量怎样变化。EEG Conformer 论文报告了加入注意力的收益，也发现头数和层数并非越多越好；池化窗大小会显著影响 token 的信息质量。对 EEG 来说，先把 token 做好，可能和后面堆多少层同样重要。EEG Conformer 消融部分

CT-MIFNet 的结果则提醒我们：验证方式也要随研究问题一起看。它在 2a、2b 上采用同一受试者的跨 session 测试，在疼痛数据上对所选九位受试者做五折验证；这些都不是“拿一个新受试者来立刻预测”的实验。若下一步要证明真正的跨人泛化，训练折中必须完全排除测试受试者，并把按人拟合的空间滤波、标准化以及参数调优一同限定在训练侧。尤其在样本少、模型模块多的时候，只报同一协议里的最高分，很容易让人低估选择偏差。

报告结果时，不妨同时给出 Accuracy、Kappa、各类别召回率、Macro-F1、混淆矩阵和受试者间差异。如果某一类样本很多，模型全猜这类也可能得到看似不错的准确率；而平均分数还可能掩盖某几位受试者的明显失败。至于模型内部的注意力图或 CAT 地形图，它们能帮助提出“模型可能在看哪里”的问题，却不能替代这些独立测试。

这些指标也各自回答不同的问题。Accuracy 是正确试次数除以总试次数；Kappa 可写成 $\kappa=(p_o-p_e)/(1-p_e)$ ，其中 $p_o$ 是观察到的一致率， $p_e$ 是依据真实标签和预测标签的边际分布估计的偶然一致率。Macro-F1 则先对每一类算精确率、召回率及其调和平均，再对类别等权平均。遇到类别不平衡时，至少应连同每类样本数和混淆矩阵给出这些值，才知道高分来自普遍识别，还是来自某一类占比较大。

比较两个模型时，统计检验的样本单位也必须交代清楚。如果任务声称“受试者间更稳定”，应先对同一受试者得到成对分数，再在受试者层面比较；不能把同一人相邻、甚至重叠的窗口当成许多独立受试者来扩大样本量。CT-MIFNet 表中几组相近模型的均值差异没有达到显著，正说明“平均值高一点”和“有充分证据认为总体更好”是两个命题。小样本下，均值、离散程度、每位受试者的方向以及置信区间，比单独报告一个最高准确率更有解释力。

最后还有上线时才会显现的限制。前面的示例收集完整 4 秒窗口后再给分类结果，注意力也没有因果掩码；它可以在窗口内部双向参考信息，但不能在窗口尚未结束时假装已经看到了未来数据。若目标是逐时刻在线反馈，需要明确允许多少等待时间，并相应调整窗口、注意力掩码或整体结构。模型是否好用，最终是任务定义、信号质量、输入设计、独立验证与延迟共同决定的。

总结

Transformer 的故事先发生在序列建模中：注意力让模型按当前需要选择信息，Transformer 则把多头自注意力与前馈网络、残差、归一化和位置信息连成完整架构。把它带到 EEG 时，最关键的一步不是立刻写出 $QK^{\mathsf T}$ ，而是决定连续、多通道、有噪声的波形该怎样变成 token。

EEG Conformer 展示了一条清楚的路线：卷积先提取局部时空特征，池化把它们整理成时间序列，自注意力在窗口内连接不同位置，分类头汇总后输出标签。CT-MIFNet 在此基础上追问另一件事：同一段 EEG 的时域、频域与空间信息怎样互相补充，跨分支交互又能否在较长序列上更省资源？于是它采用双分支、多尺度卷积与沿通道计算的 CCA。两项研究的问题不同，实验协议也不同；不能仅凭模型名字或一行平均准确率决定取舍。

读其他 EEG Transformer 论文，也可以沿着同样的线索发问：token 从何而来？注意力沿哪条轴计算？“全局”究竟覆盖多长时间？频域表示如何构造？性能又是在什么数据划分和延迟要求下得到的？这些问题比记住模型名字更能帮助我们判断一项设计是否真正适合自己的任务。
