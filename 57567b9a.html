IEEE TPAMI | LLaFS++：利用大语言模型重新定义少样本图像分割

发表于 2026-05-08 分类于 🌙进阶学习 ， ⭐SCNU BCI团队 ， 💫学习报告 阅读次数： Valine：
本文字数： 2.9k 阅读时长 ≈ 7 分钟

该论文发表于人工智能领域顶级期刊IEEE Transactions on Pattern Analysis and Machine Intelligence (TPAMI) 2025，题目为《LLaFS++: Few-Shot Image Segmentation with Large Language Models》。

新加坡科技设计大学（SUTD）的 Lanyun Zhu 为本文第一作者，其导师Jun Liu教授为通讯作者 。

论文链接： https://ieeexplore.ieee.org/document/10555132

论文概要

尽管少样本分割（FSS）取得了快速进展，但现有方法仍受限于少量标注样本所提供的有限且偏置的信息 。本文提出了开创性的框架 LLaFS++，首次将大语言模型（LLMs）引入 FSS 领域并取得显著成功 。LLaFS++ 利用 LLM 蕴含的海量先验知识来指导分割，有效弥补了样本信息的不足 。

通过引入多模态指导、伪样本课程学习 pretraining 以及消除幻觉的预测策略，LLaFS++ 在 PASCAL-5i、COCO-20i 和 FSS-1000 等多个数据集上刷新了 SOTA 记录，展示了 LLM 在处理少样本视觉任务中的巨大潜力

研究背景

少样本分割要求模型仅通过极少数标注示例（支持图像）来识别并分割新类别的查询图像 。传统 FSS 方法（如基于原型提取的方法）由于过度依赖受限的支持数据，往往面临信息约束，导致精度不足 。

虽然 CLIP 和 SAM 等基础模型已被引入，但 CLIP 参数规模相对有限，而 SAM 缺乏类别感知能力，两者均无法提供充足的辅助信息 。LLMs 凭借其在 NLP 领域的强大 Few-shot 学习能力和博大的知识库，为突破 FSS 性能瓶颈提供了全新可能 。

研究方法

LLaFS++ 框架将 LLM 从辅助角色提升至核心地位，直接生成分割结果 。其核心架构包含特征提取器、任务定制指令和 LLM 预测头。

图1展示了从输入支持/查询图像到特征提取（Q-Former）、指令拼接、LLM 预测多边形顶点，最后经过细化网络（Refinement Network）输出掩码的全流程 。

图1 模型整体框架

(1) 任务定制化指令设计

为了让擅长处理文本的 LLM 执行像素级分割，LLaFS++ 采用了两项核心设计：

多边形表征：将分割结果表示为 16 边形的顶点坐标。这种方式比预测原始像素更具 Token 效率 。

细粒度上下文指令：模拟人类”由抽象到具体”的认知机制 。首先由 LLM 提取目标类别的详细属性（如熊猫的”黑耳朵”、”黑眼圈”），然后通过区域-属性对应表将这些属性与支持图像的特定区域对齐 。如图2所示，该图（a）展示了属性（如黑眼圈、白脸）在支持图像上的相似度图（Similarity Maps），（b）展示了如何构建区域-属性对应表 。

图2 区域-属性对应表

(2) 伪样本课程预训练

由于分割数据集规模有限，LLaFS++ 提出了一种伪样本生成策略 ：

伪样本生成：利用贝塞尔曲线和高斯噪声生成具有随机形状和纹理的伪支持-查询对 。

课程学习：从简单任务（较少顶点预测、前景背景差异大）逐渐过渡到复杂任务 。如图3所示，直观展示预训练的三个阶段（开始，中间，最终阶段），体现了图像理解难度和多边形生成难度的递增。

图3 不同训练阶段的伪样本示例

(3) 幻觉缓解预测策略

LLaFS++ 引入了对比预测方法来解决”过度分割幻觉（即模型仅分割局部区域而非整体）。通过在 LLM 的最后一层屏蔽全局类别 Token，强制产生”局部偏差”的预测，再通过对比消除这些错误预测 。

实验结果

作者在三大公开数据集上进行了广泛实验 。结果表明，LLaFS++ 在各项指标上均刷新了少样本分割（FSS）的性能纪录 。

(1) 核心性能基准：全面刷新 SOTA

LLaFS++ 不仅显著优于传统的原型引导方法（如 BAM、PFENet++），也超越了同样基于语言模型（如 MIANet）或视觉语言模型（如 PGMA-Net）的方法 。

在包含 1000 个类别的 FSS-1000 数据集上的强劲表现，充分证明了 LLM 蕴含的广泛知识赋予了模型卓越的类别泛化能力 。

(2) 与同类 LLM 分割模型直接对比

作者将 LLaFS++ 与近期发表的 LLM 分割模型（如 LISA、PixelLM）进行了公平对比 。即便这些模型也拥有 7B参数规模，但在少样本场景下仍大幅落后于LLaFS++ 。

LLaFS++ 的优势不仅在于使用了大模型，更在于其任务定制指令和伪样本预训练机制的协同作用。

(3) 消融实验与可视化分析

通过消融研究，作者验证了各个创新模块对性能的贡献：

大语言模型的决定性作用：移除 LLM 模块后，mIoU 骤降 15.5%，证明了语言先验在建立视觉-语义联系中的核心价值 。

幻觉缓解策略的有效性：新提出的对比预测推理方法将过度分割幻觉的发生率（FH）从 11.8% 降至 3.9%，且仅增加约 3% 的计算开销 。

课程预训练的必要性：若不采用伪样本课程学习，mIoU 会显著下降 10.3%，表明该机制对 LLM 理解复杂图像空间逻辑至关重要 。

如图4，本实验通过分割结果可视化： Row 1-2：展示模型在处理具有相似外观干扰（如多只动物）时的鲁棒性 。 Column (c) vs (d)：直观对比原 LLaFS 与 LLaFS++，展示后者如何通过对比推理纠正”局部分割”错误，捕捉完整目标边界 。Column (e)：展示细化网络（Refinement Network）如何进一步优化多边形边缘，提升分割精度 。

图4 LLaFS和LLaFS++的分割结果可视化

结论

本文提出了一种全新的 LLM 驱动型少样本分割框架 LLaFS++，通过细粒度属性对齐与多边形表征生成，成功重构了视觉分割任务。该方法通过将 LLM 从”辅助特征提取”转变为”端到端推理核心”，克服了传统 FSS 模型对有限标注样本的过度依赖 。

研究证明，LLM 蕴含的广泛语言先验能够有效弥补视觉样本的匮乏 。LLaFS++ 在处理从未见过的新类别时，表现出了极强的类别泛化性，其在包含千类物体的 FSS-1000 数据集上高达 93.8% 的准确率证明了”语言指引视觉”的巨大潜力。

通过创新的伪样本课程预训练机制，模型克服了 LLM 在处理非结构化图像坐标时的收敛难题，显著提升了对复杂空间逻辑的理解 。这一机制使模型在不牺牲计算速度的前提下，能够探索更深层次的隐含特征用于精确分割 。

LLaFS++ 引入的对比预测推理策略，在几乎不增加额外推理成本的情况下，将过度分割幻觉率从 11.8% 降至 3.9%。 这种利用 LLM 内部隐藏状态进行自我纠偏的设计，避免了传统模型中因全局信息丢失而造成的定位偏差，为实时视觉感知设立了新的基准 。

实验结果显示，LLaFS++ 在 PASCAL-5i、COCO-20i 等主流数据集上均刷新了 SOTA 纪录，尤其在 1-shot 挑战下取得了突破性进展 。此外，该模型对弱标签（Bounding Box）的兼容性以及在跨域测试中的稳健表现，证明了其在自动驾驶、医疗影像分析等对标注成本极其敏感的实际场景中，具有广阔的应用前景 。
