Nature | DeepSeek-R1: 通过强化学习激励大语言模型的推理能力

发表于 2026-01-30 分类于 🌙进阶学习 ， ⭐SCNU BCI团队 ， 💫学习报告 阅读次数： Valine：
本文字数： 6.3k 阅读时长 ≈ 16 分钟

该论文发表于 Nature刊期，发表日期 2025 年 9 月 18 日，卷号 645，页码 633–638，题目为《DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning》。DeepSeek-AI 团队为本文核心研发力量。

论文链接：

Nature：https://www.nature.com/articles/s41586-025-09422-z

arXiv：https://arxiv.org/abs/2501.12948v1

论文概要

本文提出第一代推理模型 DeepSeek-R1-Zero 与 DeepSeek-R1，旨在攻克大模型推理能力提升中依赖海量监督数据、可读性不足等核心难题。DeepSeek-R1-Zero 首创无监督微调（SFT）前置步骤的大规模强化学习（RL）训练范式，通过纯 RL 过程自主进化出自我验证、反思等强大推理行为；针对其可读性差、语言混合等问题，DeepSeek-R1 引入冷启动数据与多阶段训练 pipeline，最终推理性能媲美 OpenAI-o1-1217。团队进一步基于 Qwen 和 Llama 架构，从 DeepSeek-R1 蒸馏出 1.5B 至 70B 参数的 6 个稠密模型并开源，其中 32B 和 70B 模型刷新稠密模型推理基准纪录。该工作验证了纯 RL 激励推理能力的可行性，为通用推理模型研发提供了新范式，开源资源亦将助力社区推进相关研究。

研究背景

大语言模型（LLM）正快速迭代演进，逐步拉近与通用人工智能（AGI）的距离，推理能力作为核心短板，成为学界研究焦点。OpenAI o1 系列通过延长思维链（CoT）长度实现推理性能突破，但测试时的有效扩展问题仍未解决；现有方法如过程奖励模型、搜索算法等，均未能达到 o1 系列的通用推理水平。传统推理模型优化依赖大量监督数据，不仅数据收集耗时耗力，还可能限制模型自主进化潜力，而纯 RL 训练虽具潜力，却面临冷启动不稳定、输出可读性差等挑战。因此，开发无需依赖海量监督数据、兼具高性能与实用性的推理模型，成为大模型领域的关键。

研究方法

1. GRPO(Group Relative Policy Optimization)：群体相对策略优化

1.1 PPO不足：作为 RLHF 框架下的经典算法，PPO 在大模型训练中虽以稳定性著称，但 Critic（价值模型）的设计缺陷长期制约其效率与实用性。PPO 需单独训练一个与策略模型（Actor）规模相当的 Critic 网络，用于估计状态价值并计算优势值，这不仅直接增加了近 50% 的显存占用和计算成本，还存在样本效率低、对超参数敏感的问题。更关键的是，Critic 的价值估计依赖全局基准，在 LLM 推理等奖励稀疏或噪声较大的场景中，易出现估计偏差，且其裁剪损失与信任区域原则存在错位，可能导致训练过程中价值预测偏离最优方向，影响策略更新的稳定性。此外，LLM 训练中通常仅对最终 token 进行奖励打分，进一步加剧了 Critic 训练的复杂性，使其难以精准捕捉多步推理的价值逻辑。

1.2 GRPO的提出：为解决 PPO Critic 带来的一系列痛点，Group Relative Policy Optimization（GRPO）应运而生，其核心创新在于用 “组内相对评估” 替代传统价值模型，从根源上规避了 Critic 的固有缺陷。GRPO 无需额外训练 Critic 网络，通过对同一输入采样生成多个输出组成评估群体，利用组内奖励的均值和标准差进行归一化，直接计算相对优势值（Aᵢ = (rᵢ - μᵣ)/σᵣ），既简化了优势估计流程，又减少了奖励方差带来的干扰。这一设计使显存占用降低 40%-50%，训练速度提升 30% 以上，大幅降低了大规模训练的资源门槛。同时，组内相对比较的机制让模型更聚焦局部竞争而非全局绝对价值，对噪声奖励的容忍度更高，在推理等稀疏奖励场景中表现出更强的鲁棒性。GRPO 还保留了 PPO 的裁剪机制与 KL 散度约束，通过在损失函数中直接引入策略与参考模型的 KL 正则化，既保证了策略更新的稳定性，又简化了训练流程，实现了效率与性能的双重优化。在实际推理任务中，GRPO 微调后的模型准确率显著高于基线，充分印证了其在提升 LLM 推理能力上的优势。具体而言，对于每个问题，GRPO从旧策略

2. 训练设置与细节

2.1 群体采样机制： 群体采样机制既是 GRPO 算法的核心执行载体，也是 DeepSeek-R1-Zero 实现相对优势评估的关键基础。针 对每个输入问题，模型会在当前策略下采样生成 N 个回答，构成一个评估组，所有采样均通过设置唯一随机种子、随机化采样顺序及每 N 次采样后重置模型缓存的方式，确保样本独立性，规避 GPU 缓存效应与内部状态累积带来的相关性干扰。采样参数上，采用温度 0.6 与 Top-p 0.95 的组合，既避免温度过低导致的局部最优陷阱，又防止温度过高引发的推理连贯性下降，同时通过 Top-p 筛选累计概率达 95% 的候选词，排除极端低概率词的干扰。这种单问题多采样的设计，无需依赖外部基准，仅通过组内样本对比即可完成优势评估，为后续奖励计算与策略更新提供了核心数据支撑。

2.2 计算reward： 奖励是训练信号的来源，它决定了强化学习的优化方向。为了训练DeepSeek-R1-Zero，采用了一种基于规则的奖励系统，该系统主要包含两种类型的奖励：

  • 准确性奖励：准确性奖励模型用于评估响应是否正确。例如，对于具有确定性结果的数学问题，要求模型以指定格式（如在方框内）提供最终答案，以便基于规则可靠地验证其正确性。同样，对于力扣（LeetCode）问题，可以使用编译器根据预定义的测试用例生成反馈。
  • 格式奖励：除了准确性奖励模型外，还采用了一种格式奖励模型，该模型强制模型将其思考过程放在”“和”“标签之间。

两种奖励直接相加得到每个输出序列的原始奖励值rᵢ

2.3 基于LOSS(损失函数)的模型更新： 模型参数更新以 GRPO 目标函数为核心，通过优化策略使模型更倾向于生成优势值较高的输出序列，同时兼顾更新稳定性与知识保留。损失函数主要由策略梯度项、裁剪约束项(Clip) 与KL 正则化项构成：策略梯度项基于优势值引导参数更新，使优势值为正的输出（组内表现优于平均水平）生成概率提升，优势值为负的输出生成概率降低；裁剪约束项(Clip)将策略更新比率限制在合理范围，避免单次更新幅度过大导致训练震荡或崩溃，确保策略迭代的渐进性；KL 正则化项（KL 散度约束值 0.001）用于衡量新策略与旧策略的差异，抑制策略突变，防止模型遗忘已习得的推理模式。整个更新过程以评估组为单位，基于采样生成的输出序列、计算得到的优势值与损失函数，反向传播调整模型参数，每轮迭代后评估模型在基准任务上的性能，直至模型准确率不再显著提升、参数趋于稳定，完成训练收敛。这种损失函数设计，在规避 Critic 网络缺陷的同时，实现了效率、性能与稳定性的三重平衡。

4. 自我进化和顿悟时刻（Aha moment）

DeepSeek-R1-Zero 自我进化的核心特征，是在无显式编程或标注数据引导的纯强化学习迭代中，自发涌现出高阶推理能力，且伴随明显的”顿悟时刻”(Aha moment)。训练初期，模型输出多为零散推理步骤，正确率较低，仅能完成基础逻辑推导；随着数千步 GRPO 迭代推进，模型逐渐学会整合推理链条、自我验证中间结果，进而涌现出反思纠错行为——针对复杂数学题或代码任务，会先尝试一种解法，发现错误后主动回溯调整思路，重新推导直至得到正确答案(如表2所述)。顿悟时刻多出现于训练中期收敛节点，表现为模型性能在短迭代周期内突然跃升，pass@1 得分从阶段性瓶颈快速突破，同时推理模式发生质变，从”盲目尝试”转向”有规划推导”，这种能力跃迁并非源于数据或算法调整，而是模型通过持续的组内相对优化自主习得，印证了纯强化学习激发 LLM 深层推理潜能的可行性。

5. 冷启动与蒸馏

5.1 冷启动：收集数千条长 CoT 高质量数据微调基础模型，定义「推理过程 + 总结」的可读输出格式，奠定推理与非推理能力基础；

与DeepSeek-R1-Zero不同，为了避免基础模型在强化学习训练初期出现不稳定的冷启动阶段，对于DeepSeek-R1，构建并收集了少量长思维链数据来微调模型，将其作为初始的强化学习智能体。

5.2 蒸馏：小模型的推理能力赋能

利用 DeepSeek-R1 生成的 800k 训练样本，对 Qwen2.5 和 Llama3 系列模型进行直接蒸馏，仅通过 SFT 即实现推理能力跃升。蒸馏模型无需额外 RL 训练，即可在多个基准测试中超越同等规模模型，验证了大模型推理模式迁移的有效性。

为了让更高效的小型模型具备像DeepSeek-R1那样的推理能力，使用经DeepSeek-R1筛选的80万个样本，直接对Qwen（Qwen，2024b）和Llama（AI@Meta，2024）等开源模型进行微调。的研究结果表明，这种简单直接的蒸馏方法显著提升了小型模型的推理能力。在此使用的基础模型包括Qwen2.5-Math-1.5B、Qwen2.5-Math-7B、Qwen2.5-14B、Qwen2.5-32B、Llama-3.1-8B以及Llama-3.3-70B-Instruct。选择Llama-3.3是因为其推理能力略优于Llama-3.1。

对于蒸馏模型，仅应用监督微调（SFT），不包含强化学习（RL）阶段，尽管加入强化学习本可以显著提升模型性能。此处的主要目标是证明蒸馏技术的有效性，将强化学习阶段的探索留给更广泛的研究社区。

表 3 | DeepSeek-R1 与其他代表性模型的比较

在多领域基准测试中，DeepSeek R1 整体表现处于顶级梯队：其与 DeepSeek V3 均采用 MoE 架构，激活参数 37B、总参数 671B。在英语任务中，DeepSeek R1 在 MMLU-Redux（92.9）、DROP（92.2）、AlpacaEval2.0（87.6）等指标上表现突出，ArenaHard（92.3）接近 OpenAI o1-mini；代码任务中，其 LiveCodeBench（65.9）略超 OpenAI o1-1217，Codeforces Rating（2029）与 o1-1217（2061）相当；数学任务里，MATH-500（97.3）表现领先，AIME 2024（79.8）与 o1-1217（79.2）持平；中文任务中，CLUEWSC（92.8）、C-Eval（91.8）大幅超越 Claude-3.5、GPT-4o 等模型。这一结果印证了 DeepSeek R1 多阶段训练方案的有效性，使其在推理、代码、多语言等任务中达到当前顶尖水平，兼具强推理能力与全场景适配性。

如表4所示，仅通过蒸馏DeepSeek-R1的输出，就能使高效的DeepSeekR1-7B（即DeepSeek-R1-Distill-Qwen-7B，下文缩写相同）在所有方面超越GPT-4o-0513等非推理模型。DeepSeek-R1-14B在所有评估指标上均超过QwQ-32BPreview，而DeepSeek-R1-32B和DeepSeek-R1-70B在大多数基准测试中显著优于o1-mini。这些结果表明了蒸馏技术的巨大潜力。此外，发现对这些蒸馏后的模型应用强化学习（RL）能带来显著的进一步提升。认为这值得进一步探索，因此在此仅展示简单的监督微调（SFT）蒸馏模型的结果。

结论

本文通过纯 RL 训练与多阶段优化，成功研发出高性能推理模型 DeepSeek-R1 系列，验证了无需海量监督数据即可激励大模型推理能力的核心假设。DeepSeek-R1 在多项基准测试中媲美 OpenAI-o1-1217，开源的全尺寸蒸馏模型为社区提供了高效推理工具。未来团队将重点优化模型的通用能力（函数调用、多轮对话等）、解决多语言混合问题，并扩展软件工程任务的 RL 训练数据，进一步提升模型实用性与泛化性。该工作不仅为推理模型训练提供了新范式，也为 AGI 方向的核心能力突破奠定了基础。
