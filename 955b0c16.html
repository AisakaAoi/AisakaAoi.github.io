论文概要

耳鸣由听觉通路过度兴奋所致，常伴随严重睡眠损害，但其干扰入睡、破坏睡眠维持的神经振荡机制尚不明确。华南理工大学李远清、黄琪云团队近期于《Sleep Medicine》刊发研究发现，耳鸣患者完整睡眠周期（涵盖入睡启动与睡眠维持全过程）存在时序递进的层级化皮层高觉醒特征：闭眼休息以颞叶异常为主，非快速眼动期（NREM）转移至前额叶，快速眼动期（REM）扩散至顶、枕广泛脑区。这种基于谱分析的异常神经模式得到非周期斜率、样本熵双重指标的趋同验证。研究提示，睡眠全程皮层觉醒时空紊乱源自神经激活-抑制失衡。该研究完善了耳鸣合并睡眠障碍的动态神经振荡机制阐释，为临床靶向改善耳鸣患者入睡困难、睡眠维持受损提供重要理论支撑。

研究背景

耳鸣是一种常见的听觉异常，表现为无外界声源刺激时，个体仍主观感知到蝉鸣、嗡嗡声等异常声响。超40%的耳鸣患者合并入睡困难、夜醒频繁等睡眠问题。耳鸣与睡眠障碍相互加剧、形成恶性循环，因此改善睡眠、阻断该负性循环，是耳鸣临床干预的关键靶点。

病理层面，耳鸣多由耳蜗毛细胞损伤诱发，可进一步导致听觉通路重塑与神经过度激活。现有研究表明，耳鸣并非局限于听觉系统的局部病变，而是累及多脑区、边缘系统及自主神经系统的广泛性神经网络功能异常。患者对耳鸣的过度关注可持续激活相关神经环路，增高皮层觉醒水平，形成认知与生理双重高觉醒状态，这被认为是耳鸣诱发睡眠障碍的核心神经机制。目前的假说认为，耳鸣异常神经网络可拮抗睡眠-觉醒调控系统，使大脑持续处于兴奋状态、破坏睡眠稳态；而睡眠压力又可暂时缓解耳鸣感知，二者存在复杂的交织关系。目前，仍缺乏脑电与神经影像的直接实证证据阐释耳鸣干扰睡眠的具体内在机制。但可以推测的是，耳鸣异常脑网络对睡眠的干扰具有显著的睡眠阶段依赖性，其皮层激活模式可随睡眠进程动态演变，这为探索睡眠状态下耳鸣的神经振荡特征提供了崭新研究思路。

本研究以”皮层高觉醒是耳鸣合并睡眠障碍的病理基础”为核心假说。人类大脑神经振荡存在高频对应觉醒、低频介导睡眠的保守节律转换规律，因此可借助脑电技术客观量化并验证耳鸣相关的皮层高觉醒表现。基于此，本研究纳入52名耳鸣患者及52名年龄、性别匹配的健康对照，采集两组受试者睡前闭眼放松及全夜睡眠脑电数据，通过基线校正构建动态神经动力学指标，旨在验证耳鸣患者存在持续性皮层高觉醒状态，阐明其睡眠异常的内在神经振荡机制，揭示耳鸣相关脑区在不同睡眠阶段的特异性激活特征与行为学耦合规律。

研究方法

基于健康人清醒-睡眠转换中大脑神经振荡轨迹稳定保守的固有特征，本研究超越常规组间直接对比，建立了基线校正分析框架，以量化受试者睡前闭眼放松与睡眠维持阶段神经振荡指标的相对波动，消除个体基线差异干扰，实现被试内耳鸣相关高觉醒微弱神经动态的稳定追踪（见图1）。在本研究中，我们采用静坐闭眼放松范式模拟人体躺姿入睡前的闭眼放松状态，以减少躺姿状态电极帽佩戴带来的个体觉醒差异。

闭眼放松状态基线‌ ：本研究假定受试者从闭眼休息状态向深度放松状态转换的过程中，脑电低频活动逐渐增强、高频活动逐渐减弱。为识别耳鸣皮层高觉醒状态对应的异常神经活动，本研究将5分钟闭眼放松脑电记录划分为T1（第1 min）、T3（第3 min）、T5（第5 min）三个时段，以T1时段数据作为初始基线。通过计算T1与T5时段的特征值差值，量化放松诱导的神经动态改变，单被试(α+β)/δ指标变化量的计算公式如下：

实验结果

（一）睡前闭眼休息状态下耳鸣患者颞叶脑区呈高觉醒特征

在5分钟睡前闭眼休息阶段，两组被试全脑水平各频段功率谱密度无显著差异（图2A）。双因素方差分析结果显示，耳鸣组与对照组均呈现显著的时间-频段交互效应（耳鸣组：F(4,204) = 6.08，p < 0.001；对照组：F(4,204) = 14.61，p < 0.001）。经FDR校正的事后配对t检验结果表明，对照组在T1至T5时段呈现出高频脑电节律衰减、低频节律增强的典型睡前放松特征，表现为α、β频段功率显著降低，δ频段功率显著升高（α：t(51) = 6.94，p < 0.001；β：t(51) = 4.17，p < 0.001；δ：t(51) = 3.01，p = 0.009；图2B左）；然而，耳鸣组仅表现出α、β频段功率下降，δ频段未出现显著统计学变化（t(51) = 0.93，p = 0.36；图2B右），提示耳鸣患者存在频段特异性的脑电节律失衡。

为量化潜在的频段失衡，本研究计算了T1-T5时段全脑水平(α+β)/δ比值变化量Δ(α+β)/δ。结果显示耳鸣组全脑水平Δ(α+β)/δ显著低于对照组（t(102) = 2.34，p = 0.02；图2C）。全脑拓扑图结果进一步表明，该指标的组间差异可能集中于颞叶脑区（图2E）。进一步的交互效应分析显示，右侧颞区、顶区存在显著交互效应（右颞区：F(2,204) = 4.79，p = 0.009；顶区：F(2,204) = 5.15，p = 0.007），左侧颞区呈边缘显著水平（F(2,204) = 2.63，p = 0.075），而额区与枕区无此效应，见图2D。

事后配对比较（经FDR校正）显示，两组的额叶区域从T1到T5，(α+β)/δ显著降低，枕区指标则无显著变化；对照组双侧颞区及顶区该比值均随时间显著降低（左颞区、右颞区、顶区均p < 0.001），而耳鸣组的这些脑区该指标未随时间显著降低（均p > 0.70），提示这些神经动力学变化模式存在明显组间分化（图2D）。脑区水平定量比较结果进一步验证，耳鸣组双侧颞区Δ(α+β)/δ显著低于对照组（左颞区：t(102) = 2.02，p = 0.025；右颞区：t(102) = 2.77，p = 0.007；图2F），其余脑区未见组间差异。

基于非周期斜率与样本熵的分析结果与上述结论一致，进一步佐证耳鸣患者颞叶存在异常神经动态活动，特别是右侧颞区（ΔSlope：t(102) = 2.55，p = 0.028；ΔSampEn：t(102) = 2.42，p = 0.033）。

（二）NREM-REM高觉醒神经模式的时空迁移：从前额叶扩展到顶枕区

本研究对各睡眠阶段分别进行双因素方差分析，检验频带功率的交互效应。结果显示，N2期与N3期存在显著的组别-频段交互效应（N2：F(4,360) = 8.61，p < 0.001；N3：F(4,360) = 4.93，p < 0.001），而REM期交互效应无统计学差异（F(4,360) = 1.36，p = 0.25），见图3A。经基线校正后，各睡眠阶段组别-频段交互效应均显著（N2：F(4,360) = 5.95，p < 0.001；N3：F(4,360) = 3.11，p = 0.015；REM：F(4,360) = 3.31，p = 0.011，图3B），提示两组睡眠过程脑电功率谱变化模式存在显著分化。

事后检验表明，耳鸣组NREM期γ频段功率显著升高（N2：t(90) = 2.99，p = 0.013，图3A左；N3：t(90) = 3.57，p = 0.003，图3A中），且全睡眠阶段δ、θ低频功率整体降低，在REM期尤为突出（δ：t(90) = 3.01，p = 0.017；θ：t(90) = 2.37，p = 0.049，图3A右）。基线校正结果进一步证实耳鸣组存在频段特异性失衡：相较于闭眼静息基线，其N2(Δδ：t(90) = 3.29，p = 0.007；Δθ：t(90) = 2.23，p = 0.049，图3B左)、REM期（Δδ:t(90) = 2.60，p = 0.028；Δθ:t(90) = 3.01，p = 0.018，图3B右）低频功率增加幅度更低，同时NREM期γ频段功率衰减程度显著弱于对照组（N2期：t(90) = 2.50，p = 0.036，图3B左；N3期：t(90) = 2.68，p = 0.043，图3B中）。

为量化高低频振荡失衡程度，本研究采用复合指标——γ/(δ+θ)比值，并计算各睡眠阶段相对基线的变化量Δγ/(δ+θ)，以表征睡眠期高觉醒神经动力学特征。结果显示，REM期耳鸣组全脑水平Δγ/(δ+θ)显著低于对照组（t(90) = 3.82，p < 0.001，图4B）。图4A 为该指标通道水平全脑拓扑分布。双因素方差分析显示，各睡眠阶段在脑区水平均存在显著交互效应（N2：F(4,360) = 4.64，p = 0.001；N3：F(4,360) = 2.43，p = 0.047；REM：F(4,360) = 2.62，p = 0.035，图4C），提示反映皮层高觉醒的指标差异具有明显的脑区分布特征。事后分析显示，耳鸣组各睡眠阶段额叶Δγ/(δ+θ)均显著降低（N2：t(90) = 3.26，p = 0.008；N3：t(90) = 2.92，p = 0.021；REM：t(90) = 2.38，p = 0.033，图4C），且额叶高觉醒异常在REM期进一步扩展至顶区与枕区（顶叶：t(90) = 4.00，p <0.001；枕叶：t(90) = 4.05，p < 0.001，图4C右）。

非周期斜率与样本熵指标的验证结果与上述模式趋同：耳鸣组全睡眠阶段额叶指标显著异常降低，且REM期顶、枕脑区同步出现类似异常，见图4d2/d4。指标拓扑图分布进一步证实了耳鸣大脑这种异常神经振荡的时空模式，见图4d1/d3。

（三）临床行为指标对耳鸣患者脑电振荡差异的潜在影响

皮尔逊相关分析表明，耳鸣严重程度与睡眠质量呈中等正相关（r = 0.382，p = 0.005，图5A左），与既往研究相符；该相关性主要源于睡眠紊乱维度（r = 0.484，p < 0.001，图5A右），与入睡潜伏期无显著关联（r = 0.147，p = 0.301，图5A中）。

以双侧颞区平均Δ(α+β)/δ表征的耳鸣神经动力学异常，与入睡潜伏期显著相关（r = -0.420，p = 0.002，图5B）。多元线性回归校正耳鸣严重程度、睡眠维持质量及年龄后，此关联仍具有统计学意义（β = -0.039，p < 0.001，表2）。N2期全脑水平δ频段功率变化值与睡眠紊乱评分显著正相关（r = 0.465，p < 0.001，图5C）。另一多元线性回归模型在校正耳鸣严重程度、睡眠潜伏期、整体睡眠质量及年龄后，该相关效应稳定存在（β = 0.038，p < 0.001，表2）。其余脑电振荡异常指标与临床量表无显著相关性。

结论

这项发表在《Sleep Medicine》的研究基于基线校正方法构建睡眠状态依赖性脑高觉醒指标，纳92名受试者追踪全清醒-睡眠周期的神经动力学特征。经多类神经振荡指标趋同验证，研究阐明了耳鸣患者睡眠异常的高觉醒神经振荡机制，揭示耳鸣人群入睡困难、睡眠维持障碍的行为学评估结果与客观神经评估间的关联。重要的是，通过追踪睡眠进程中的神经动力学演变轨迹，本研究明确了耳鸣患者大脑从闭眼静息基线到NREM、再到REM睡眠阶段层级化、脑区特异性的皮层异常激活模式。因此，该研究深化了对耳鸣觉醒-睡眠周期状态依赖性异常神经网络机制的理解，研究所揭示的耳鸣特异性睡眠时空神经动力学特征，可为靶向睡眠周期开展耳鸣神经调控干预提供重要理论依据。
