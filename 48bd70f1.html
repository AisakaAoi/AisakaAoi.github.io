AAAI 2026 | SUGAR：结合视觉-运动知识学习骨骼表示以进行动作识别

南开大学周宇团队在人工智能领域顶级国际会议The Fortieth AAAI Conference on Artificial Intelligence (AAAI-26)发表动作识别的最新研究成果。论文题为《SUGAR: Learning Skeleton Representation with Visual Motion Knowledge for Action Recognition》，第一作者为叶其朗（Qilang Ye），通讯作者为周宇教授与余梓同助理教授，主要合作作者包括来自大湾区大学、北京理工大学、华南理工大学、深圳大学等多所高校的研究人员。

论文概要

现有的动作识别研究逐渐开始探索大语言模型（LLM）的潜力，但面临两大核心挑战：一是如何让 LLM 理解非语言的人体骨骼信号，二是如何区分动作细节极其相似的细粒度动作（例如”吃零食”与”喝水”）。传统的骨骼编码方式往往缺乏高层语义引导，导致模型在处理复杂动作时判别力不足。

论文提出了一种名为 SUGAR 的新范式，旨在通过”视觉-运动”知识引导骨骼表示的学习。研究团队利用 GPT-4V 等视频大模型和 GPT-3.5 提取动作的细粒度运动描述（如手部、腿部的具体轨迹）和视觉环境知识（如场景、物体交互），并将这些丰富的文本先验知识作为监督信号，通过多实例对比学习让骨骼编码器掌握更具语义辨识度的特征。

为了解决骨骼序列过长且 LLM 难以直接处理的问题，论文设计了时间查询投影模块（TQP）。该模块能够对长达数百帧的骨骼信号进行连续建模，并将其压缩、提炼为一组精简的语言标记（tokens）。这些标记能够无缝投影到 LLM 的嵌入空间，使 LLaMA 等大语言模型不仅能准确识别动作类别，还能根据指令生成关于动作的文本描述。

实验结果表明，SUGAR 在 Toyota Smarthome 和 NTU RGB+D 等权威数据集上取得了显著的性能提升，特别是在处理具有挑战性的细粒度动作时表现尤为突出。此外，由于引入了语言模型的先验知识，SUGAR 在零样本（Zero-shot）场景下展现了极强的泛化能力，证明了将跨模态知识集成到骨骼表示学习中是提升动作识别智能化的有效途径。

研究背景

基于人体骨骼点的动作识别是计算机视觉领域的重要研究方向。相比于传统的RGB视频数据，骨骼数据仅包含人体关键点的坐标序列，具有极高的计算效率和数据简洁性。同时，它能够有效过滤背景噪声、光照变化以及衣着差异的干扰，并在涉及个人隐私的场景（如家庭监控、医疗护理）中提供更安全的保障。这使得骨骼识别在人机交互、运动康复和智慧安防等领域展现出巨大的应用潜力。

尽管骨骼识别技术取得了显著进步，但在处理”细粒度相似动作”时仍面临巨大挑战。许多日常动作在物理轨迹上高度相似，例如”喝水”与”吃零食”，或者”玩手机”与”看书”。由于传统的识别方法主要依赖骨骼点的空间几何关系和运动频率，很难仅凭几组坐标的变化来捕捉这些动作背后微小的语义差异。这种”类间相似性”成为了限制骨骼识别精度进一步提升的核心瓶颈。近年来，大语言模型（LLM）展示了惊人的常识理解与逻辑推理能力。研究者们开始思考，如果能利用 LLM 内部蕴含的丰富知识来辅助动作识别，或许能为解决细粒度识别难题提供新思路。然而，LLM 天生是为文本处理设计的，人体骨骼信号属于连续的数值型非语言信号。如何打破模态壁垒，让 LLM 能够”读懂”枯燥的骨骼坐标序列并将其转化为逻辑化的语义理解，是当前学术界亟待解决的关键课题。

目前的骨骼识别模型大多处于”闭环”状态，即仅通过单一的骨骼模态进行训练，缺乏外部知识的引导。人类在识别动作时，不仅看肢体动作，还会结合场景环境（视觉知识）和动作意图（运动知识）进行判断。因此，如何引入视觉和运动的文本先验知识，建立起骨骼表征与高层语义之间的映射关系，从而赋予模型”看图说话”和”逻辑判别”的能力，成为了本研究（SUGAR）的核心出发点。

研究方法

为了克服大语言模型（LLM）难以理解非语言类骨骼信号以及无法区分细粒度相似动作的局限性，本文提出了一种名为 SUGAR 的新型动作识别范式。该范式通过构建视觉-运动知识库并引入时间查询投影（TQP）机制，实现了骨骼特征与高层语义的深度对齐； 其整体网络结构如下图所示， 通过从知识生成、特征学习到指令微调的完整技术链路，赋予了模型精准的动作判别与语言描述能力。

一、视觉-运动知识构建 (Visual-Motion Knowledge Construction)

为了赋予模型区分细粒度动作的”常识”，研究团队利用强大的视频大模型（如 GPT-4V）和文本大模型（GPT-3.5），针对每一个预定义的动作类别，自动化地生成了两个维度的海量先验知识：

运动知识（$\mathcal{T}_m$）：提供物理层面的精细解构。它详细描述了头部、躯干、上肢和下肢在时间维度上的局部运动轨迹与姿态演变，帮助模型区分如”喝水”与”吃零食”这类手部轨迹极度相似的动作。

视觉知识（$\mathcal{T}_v$）：提供环境与交互层面的上下文。它补充了纯骨骼数据中缺失的场景信息（如”在厨房”或”在办公室”）以及人与物体的交互关系（如”手中拿着杯子”或”拿着书”）。

实验结果

为全面验证基于视觉-运动知识引导的骨骼表示学习新范式 SUGAR 及其时间查询投影模块（TQP）的有效性，本文在多个公开的骨骼动作识别基准数据集与不同零样本及细粒度评估场景下开展了系统实验评估，并与多种主流动作识别方法进行了深度对比分析，具体实验设计如下：

1. 实验数据集

为全面验证 SUGAR 范式的分类准确性、细粒度动作区分度以及跨数据集/类别的泛化性能，实验选取了四种主流的骨骼动作识别基准数据库。

Toyota Smarthome (SH) 数据集 ：包含31种日常活动类别，总计生成了 16115 个视频样本 。该数据集中的动作（如日常起居行为）在运动轨迹上往往高度相似，实验将其用于重点测试模型在引入视觉-运动知识后，区分复杂细粒度动作的能力 。

NTU RGB+D (NTU 60) 数据集 ：包含60个动作类别与56880个视频样本，并提供了原始的骨骼序列 。实验将其作为基础的骨骼动作识别基准，在交叉受试者（X-sub）和交叉视角（X-view）两种协议下验证该方法相比传统骨骼识别模型的性能优势 。

NTU RGB+D 120 数据集 ：作为 NTU 60 的升级版，包含120个动作类别和超过 11.4 万个骨骼序列样本 。实验利用其庞大的数据量测试框架的大规模适应性，并将其用于零样本（Zero-shot）评估协议，即在 NTU 60 上预训练后，对 NTU 120 中的 10 个未见动作类别进行推理测试 。

PKU-MMD (PKU) 数据集 ：包含51个动作类别和 21,545 个带有骨骼数据的样本 。实验中不仅将其用于常规的动作分类测试，还将其用于跨数据集的零样本测试（即在 NTU 60 上预训练，在 PKU-MMD 上进行推断），以深入分析方法在跨域动作理解上的零样本迁移性能 。

2. 评价指标与评价标准

本文从识别精度与模型计算效率两个维度进行综合评价。识别性能方面采用平均类准确率（Mean Per-class Accuracy） 、Top-1 准确率以及 Top-5 准确率作为核心指标 ，其中重点报告跨受试者（X-sub）与跨视角（X-view）协议下的准确率及零样本（Zero-shot）场景下的 Top-1/Top-5 准确率，以反映系统在面对复杂细粒度动作及未见类别场景下的泛化与推理表现 ；效率层面则主要通过动作标记长度（Length of Action Tokens）与计算复杂度评估大语言模型输入的序列规模与计算开销 ，从而分析方法在实际部署环境（如智能监控、人机交互）中的可行性与资源需求 。

3. 实验环境与参数设置

所有实验均在两张 NVIDIA A6000 GPU 上完成 。模型的训练过程主要划分为两个阶段进行优化：

骨骼表示学习阶段 ：模型采用 CTR-GCN 作为骨骼编码器主干网络，并使用 CLIP 作为文本编码器提取特征 。批处理大小（Batch Size）设为 200（在 Toyota Smarthome 数据集上设为 100），总训练轮次为 200 epochs 。优化器采用 SGD，初始学习率设置为 0.01，并在训练过程中以 0.1 的因子进行学习率衰减 。该阶段的损失函数采用多实例对比损失来监督骨骼序列的学习 。

大模型指令微调阶段：在微调期间冻结了骨骼编码器的所有参数，并选用 LLaMA2-7B 作为大语言模型（LLM）进行推理与优化 。为了适应骨骼特征，采用了 LoRA 技术（秩参数 r=64，alpha=16）进行高效微调 。该阶段的总批处理大小设为 128，仅进行 1 个 epoch 的训练，学习率设置为2*10^-5 ，并采用交叉熵损失（Cross-Entropy Loss）来监督生成的动作目标与描述 。

关键实验与结果

一、实验数据集评估

在动作分类任务中，采用跨受试者（X-sub）与跨视角（X-view）协议下的 Top-1 准确率作为核心评价指标。对比方法包括传统的图卷积骨骼识别模型（如 CTR-GCN等）以及新兴的基于大语言模型的动作识别方法（如 LLM-AR）。

实验结果表明，在包含大量细粒度、高度相似日常动作的 Toyota Smarthome 数据集上，传统的基于线性分类器的骨骼识别方法因缺乏高级语义指导，难以有效区分相似动作。相比之下，引入视觉-运动先验知识的 SUGAR 范式表现出卓越的判别力。特别是在与同类型的基于大模型的方法（LLM-AR）对比时，SUGAR 在 X-sub 和 X-view1 协议下分别实现了 3.2% 和 14.8% 的大幅性能提升。此外，在 NTU RGB+D 60/120 以及 PKU-MMD 等通用动作基准数据集上，SUGAR 同样取得了一贯且极具竞争力的结果。上述结果充分说明，多模态（视觉-运动）知识对齐机制对于提升模型在复杂场景下的骨骼动作解析能力具有显著作用。

二、零样本跨域与跨类别推理性能分析

在零样本（Zero-shot）动作推理任务中，实验设计了两种极具挑战性的评估协议：一是跨类别测试（在 NTU 60 上预训练，在 NTU 120 的 10 个未见类别上测试）；二是跨数据集测试（在 NTU 60 上预训练，直接在 PKU-MMD 上推断）。评价指标采用 Top-1 与 Top-5 准确率。

在零样本性能分析中，实验比较了模型在面对完全陌生动作时的泛化表现。结果显示，传统依赖单一骨骼模态的模型在面对未见动作时往往出现严重的性能崩塌。然而，得益于大语言模型（LLM）庞大的内在常识以及丰富的视觉-运动先验知识的引导，SUGAR 在未见类别与跨域场景中展现出了强大的零样本泛化能力与多功能性。模型不仅能够根据骨骼标记（Tokens）准确预测出动作类别，还能以自然语言的形式生成合理的动作细节描述，实现了从”机械分类”向”语义推理”的跨越。

三、消融实验分析

（1）视觉-运动知识有效性验证

比较了模型在引入不同维度的外部知识前后的动作分类表现。实验结果显示，在骨骼表示学习阶段，若不使用知识监督，模型性能表现平庸；而引入视觉与运动文本知识引导后，模型的整体准确率实现了 4.2% 的显著提升。这表明将多维度的文本先验作为特征空间的”语义锚点”，能够有效增强骨骼特征的判别力，验证了跨模态知识注入在解决骨骼数据语义缺失问题上的关键作用。

（2）部件级监督策略验证

针对长骨骼序列向 LLM 嵌入空间的投影问题，比较了单 Q-Former 结构与本文提出的 TQP 模块的表现。结果表明，TQP 通过动态时间查询机制保持了骨骼信号的连续时序建模，使分类性能进一步提升了 2.7%。此外，针对 LLM 输入 Token 长度的测试发现，大模型并不擅长处理极其冗长的非语言 Tokens（如长度为 1000 时性能显著下降）；而过度压缩（如长度为 1）又会抹除动作的时序演变特征。实验最终确定将骨骼特征压缩至 64 个 Tokens 是平衡计算成本与分类精度的最优选择。

四、与现有方法对比分析

在与现有方法的对比分析中，本文系统地将 SUGAR 范式与传统的 SOTA 方法（如 ST-GCN、CTR-GCN）以及近期的多模态大模型框架进行了全面比较。综合表现分析表明，SUGAR 在各大主流数据库的各项评估协议上均处于领先地位。 在计算复杂度与工程部署对比方面，得益于 TQP 模块高效的序列降维能力与 LoRA 技术的参数高效微调策略，SUGAR 显著减少了 LLM 在处理超长视频/骨骼序列时的内存与计算开销。在保证高识别精度的前提下，该管线大幅降低了微调与推理的计算成本。系统性实验结果验证了 SUGAR 在准确性、泛化能力与可解释性方面相较于现有方法的综合优势，展现出在大模型驱动的智能安防与人机交互领域良好的应用前景。

结论

本文提出了一种基于视觉-运动知识引导的骨骼动作识别新范式（SUGAR），成功打破了大语言模型（LLM）难以理解非语言物理信号的壁垒。针对传统方法难以区分细粒度相似动作的痛点，该研究创新性地引入了大规模视觉与语言模型生成的视觉和运动先验知识，将其作为骨骼表征学习的”语义锚点”。同时，通过设计时间查询投影（TQP）模块，模型能够动态且高效地将冗长复杂的骨骼时序坐标流”提炼”为 LLM 可理解的固定长度标记（Tokens），实现了底层物理轨迹向高层语义空间的跨模态平滑转换。

广泛的实验结果充分验证了该范式的优越性：SUGAR 不仅在多个主流动作基准数据集（如 Toyota Smarthome、NTU RGB+D 等）上取得了超越现有先进方法的分类精度，更在极具挑战性的零样本（Zero-shot）跨域评估中展现出卓越的泛化能力。得益于大模型的内在常识与知识注入，SUGAR 赋予了传统骨骼系统强大的多功能性——它不仅能精准判定未见过的复杂动作，还能用自然语言详细描述动作的交互细节。这一成果标志着骨骼动作识别技术正跨越传统的”单一标签分类”局限，正式迈向大模型驱动的通用动作推理与语义理解新阶段。
