告别 “论文溺水”！IF=41.7《Nature》子刊作者亲授 FOCUS 法

发表于 2025-12-26 分类于 🌙逢坂杂谈与搬运 ， ⭐学术杂谈 阅读次数： Valine：
本文字数： 2.6k 阅读时长 ≈ 7 分钟

最近学术圈被指数级增长的论文淹没了，不少同学跟我抱怨：“每天新出的论文比我读过的书都多，我感觉自己快被溺死了。”

这种“论文溺水症”并非你的认知局限，而是旧有科研基建在信息洪流面前的一次整体失效。《Nature Biotechnology》（IF=41.7）近期发表了一篇重量级文章，题目一针见血：《FOCUS: An AI-assisted reading workflow for information overload》。

文章提醒我们：AI 工具不是让你停止思考，而是帮你把“机械体力活”外包，腾出脑力去捕捉那些稍纵即逝的学术 Idea。今天把这套 FOCUS 闭环 拆解给你们，并附上 10 个可以直接复制的顶级 Prompt。

什么是 “FOCUS”？

FOCUS是一套五步进阶工作流。它代表了科研人驾驭 AI 的最高智力境界：F —— O —— C —— U —— S

F｜Find（查找）：别在数据库里“捞针”，要学会“撒网”

以前我们只会逐个翻数据库。现在，你需要利用 AI 的联网能力进行“全网扫描”。

  • 不只是论文： AI 可以帮你捕捉社交媒体（X/Reddit）上正在兴起的学术讨论。
  • 评估创新性： 把你的 Idea 丢给 AI，让它快速比对近两年的学术文献，看看你是不是在“重复造轮子”。

追踪领域最新动态

Prompt 1： AI 领域进展极快。请调研今天在 X (原 Twitter)、Reddit 等平台上关于 [具体技术/主题] 的最新讨论，包括新功能开发、实际应用案例及其详细细节。

挖掘社交媒体中的深层洞察

Prompt 2： 我正在研究 [具体课题]，请搜索并提取 Reddit、X 以及各大技术博客中相关的讨论和用户体验。我想让你帮忙从这些帖子 / 讨论中提取所有关键细节和见解，以便我能将它们融入我的写作过程中。请逐一总结这些内容，并在引文中包含关键见解和细节。

针对特定课题进行“深度搜索”

Prompt 3： 我正在撰写关于 [具体主题] 的论文，重点关注 [特定维度]。请在线搜索过去 5 年内发表在权威期刊或预印本平台上的学术资源，并为我提供每个来源的核心发现摘要及其原始链接。

评估 Idea 的“新颖性”

Prompt 4： 附件是我的研究构思。请在过去两年发表的权威期刊中，搜索与该构思最相关的学术资源。我特别关注它们在新颖性上与我的想法有何关联。请提供每个来源的核心发现摘要及链接。

O｜Organize（组织）：把非结构化信息“格式化”

你听的学术讲座、播客，以前听完就忘，现在都是你的资产。

  • 视频转录： 用 Google Gemini（建议用Pro或Ultra版本）直接对 YouTube的视频进行逐字转录和编辑，让视频变成可检索的文字稿。

  • 持续知识库： 利用 NotebookLM 搭建个人知识库，让 AI 的每一个回答都基于你上传的靠谱信源，告别“一本正经胡说八道”。

音视频转录（针对 Gemini 视频功能）

Prompt 5： 请观看此链接中的视频，并逐字转录其内容。纠正大小写和标点，去除语气词，并在不改变原意的前提下轻微润色以提高可读性。

C｜Condense（浓缩）：让晦涩论文“脱水”

面对外语论文或高难度文献，很多人的反应是“搁置”。

  • 结构化拆解： 文章提倡使用详细的多步提示词，要求 AI 逐节提取每一个要点，并必须配以原文引语和具体数字。

  • AI 智能体助手： 作为开发者，我最推崇作者提到的 Gems（或 GPTs） 用法——预设好一套逻辑严密的分析框架，所有新文献丢进去，出来的都是统一格式的深度摘要。

    • Gems：是 Google Gemini 推出的功能。你可以给 Gemini 下一段长指令（System Prompt），规定它的身份和工作流程，保存后它就成了一个专门的“Gem”。

    • GPTs：是 OpenAI (ChatGPT) 推出的功能。原理一样，你可以创建一个专门用来“总结论文”或“修改格式”的定制版 ChatGPT。

💡 举个场景：你可以创建一个名为“论文脱水机”的 Gem，把作者那个最强的 Prompt 6（多步拆解）直接写进它的“说明（Instructions）”里。

以前：你每次读新论文，都要把那一大段长长的提示词复制粘贴给 AI，很麻烦。

现在：你只需要打开这个“论文脱水机”，把 PDF 丢进去，它就会自动按照“提取要点 —匹配数字—嵌入原文引语”的严谨流程给你输出结果。

核心步骤：多步论文拆解（最强 Prompt）

Prompt 6： 第一步：请作为一名好奇且严谨的读者，逐节总结这篇论文。要求：1. 提取每一个要点，不得遗漏；2. 每个要点必须包含具体细节（如数字）；3. 每个点必须附带文中的直接引语，并将其自然嵌入总结中。第二步：“基于上一步的输出，去除参考文献备注，添加一个整体综述，并按逻辑板块重新组织内容。

深度提取书籍精华（针对长文本模型）

Prompt 7： 请仔细阅读这本书，逐章提取核心见解。只使用文中的直接引语，不要添加任何书籍之外的内容。请按章节展示，并加粗显示其中的关键术语或短语。

U｜Understand（理解）：把 AI 变成你的“学术陪练”

不要被动地看，要主动地问，进行深层理解与核查。

  • 原位解析： 利用语音聊天或浏览器插件（如Gemini Chrome Extension），在阅读过程中即时提问，比如“用简单的话解释这个统计方法”。

  • 深度实时核查： 遇到可疑结论，立刻让 AI 跨源比对事实，识别研究逻辑中的漏洞。

语言细微差别学习（Socratic Partner）

Prompt 8： 你是一名资深的学术英语助手。请识别我输入的词汇/句子，提供发音、中文翻译及准确定义。请用令人印象深刻且准确的方式解释它，并提供涵盖日常生活、学术科学、哲学等领域的教育性例句。

基于特定来源的事实核查

Prompt 9： 请阅读附件中的论文及我提供的陈述。根据论文内容仔细判断该陈述是否正确，解释原因，并提供论文中的直接引语作为证据。

联网深度事实核查

Prompt 10： 请作为一名顶尖的事实核查专家，搜索支持或反驳以下观点的最佳学术资源（带活动链接），并提供给我进行二次核对。

S｜Synthesize（综合）：捕捉那些“被忽略的模式”

这是 “FOCUS” 的最后一步，也是最高阶的一步。

  • 全局盘查： 整理所有摘要和笔记，识别不同来源之间的矛盾点和尚未被解决的科研空白。
