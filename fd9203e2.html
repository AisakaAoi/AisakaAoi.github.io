华南理工大学康文雄团队在人工智能领域顶刊IEEE Transactions on Pattern Analysis and Machine Intelligence（CCF-A，JCR Q1，中科院一区 Top，IF: 23.6）发表静脉识别的最新研究成果。论文题为《Normalized-Full-Palmar-Hand: Toward More Accurate Hand-Based Multimodal Biometrics》，第一作者为研究生乔义滔，通讯作者为康文雄教授，主要合作作者为贵州民族大学罗达灿博士、华南师范大学黄俊端副研究员。

论文概要

近年来，手部多模态生物识别技术在身份认证领域取得了显著进展。然而，现有方法普遍依赖传统 ROI 裁剪或整体建模策略，缺乏统一的空间规范，难以有效解决姿态变化、区域耦合以及多模态融合不足等问题。此外，不同手指与手掌区域在判别能力上存在显著差异，若缺乏结构化约束，模型往往会产生区域偏置，限制整体性能提升。因此，如何构建标准化表示并实现部件级判别学习，成为当前全掌多模态认证研究的关键问题。

为解决上述问题，本文提出了一种标准化全掌建模与部件级监督融合框架。首先构建 Normalized-Full-Palmar-Hand（NFPH）表示，通过精细语义分割与关键点驱动的几何归一化策略，将原始手部图像映射至统一坐标空间，实现五指与手掌区域的结构化解耦表达。该过程有效降低了姿态扰动引起的类内方差，为后续特征学习提供稳定输入。

在此基础上，设计全掌认证网络 FPHandNet，实现多区域结构化特征提取与融合。FPHandNet 包含手指特征提取模块与手掌特征提取模块，并引入部件级监督策略，对五个手指特征分别施加 ArcFace Loss 与 Center Loss 联合约束，以增强类间分离度并压缩类内分布。同时，通过多特征融合模块对五指与掌部特征进行协同建模，实现全掌信息的判别性整合。

实验在 CASIA 多光谱数据库、IITD、COEP 以及 SCUT_NFPH_v1/v2 等多个公开与自建数据库上开展，涵盖可见光与近红外条件。结果表明，所提出方法在分割精度、认证性能及计算效率方面均优于传统 ROI 管线及多种主流深度方法。在十个数据库上的综合评估中，该框架在保持较低计算复杂度的同时，实现了更低的等错误率（EER）与更高的 TAR@FAR=0.01，验证了标准化建模与部件级监督策略在全掌多模态身份认证任务中的有效性与泛化能力。

研究背景

在身份认证与智能安防等应用场景中，生物识别技术已成为关键基础支撑。相较于单一模态的人脸或指纹识别，基于手部的生物特征识别因具备采集自然、信息丰富、隐私友好等优势，近年来受到广泛关注。尤其是在多光谱成像条件下，手部图像同时包含几何形状信息与内部纹理信息（如掌纹、静脉等），天然具备多模态融合潜力，为构建高精度、高安全性的身份认证系统提供了重要基础。

当前手部生物识别研究主要集中于独立模态建模，例如仅使用掌纹或仅使用手指静脉进行识别。然而，这种单区域或单模态建模方式存在明显局限：一方面，手部不同区域（五指与手掌）在几何结构、纹理分布及判别能力上差异显著，单区域难以充分利用全手信息；另一方面，真实应用环境中手部姿态变化、尺度偏移及旋转变形较为常见，导致跨样本匹配稳定性下降。因此，全掌建模面临以下几个挑战：

姿态与尺度不一致问题。 不同用户、不同采集时刻的手部摆放方式存在显著差异，导致手指间距、旋转角度及比例变化较大，若缺乏统一的几何标准化机制，将严重影响后续特征学习效果。

区域耦合与信息干扰问题。 在整手图像中，手指与手掌的纹理模式、结构特征和判别信息分布存在较强差异，若采用整体特征提取策略，网络往往偏向于信息量较大的区域，忽略部分手指特征，造成判别能力下降。

多模态融合效率问题。 形状特征与纹理特征在空间分布和统计属性上差异显著，如何在保证判别性能的同时控制模型复杂度与计算开销，是实现实际部署的关键难题。

本文认为，上述问题的本质在于缺乏一种统一的”标准化全掌建模框架”。在缺少精确区域分割与几何归一化的情况下，手部多模态信息处于高度耦合状态，使得特征学习难以实现结构化表达，从而制约了手部多模态生物识别性能的进一步提升。因此，需要构建一种从分割、归一化到多区域特征融合的系统性方法，实现手部不同区域的结构化建模与判别优化，为高精度、稳健性的手部多模态身份认证提供新的技术路径。

研究方法

基于前述分析，本文围绕手部多模态生物识别中存在的姿态不一致、区域耦合严重以及模态融合不充分等关键问题，提出了一种标准化全掌建模框架——Normalized-Full-Palmar-Hand（NFPH）。该框架从分割、几何归一化到部件级特征学习构建完整技术链路，并进一步设计全掌认证网络 FPHandNet，实现五指与手掌结构化建模与判别性融合，在多个数据库与光谱条件下显著提升认证性能。

一、标准化全掌建模框架 NFPH （Normalized-Full-Palmar-Hand）

针对现有手部识别研究缺乏统一空间建模规范的问题，文章提出标准化全掌手NFPH表示方式，从源头解决姿态变化与区域耦合问题。

1） 精细语义分割机制

文章设计轻量化手部分割网络 HSANet，对输入手部图像进行六类语义划分（五指与手掌）。该网络采用高效编码–解码结构，实现边界清晰、区域准确的分割结果，为后续独立特征建模奠定基础。

2） 几何归一化策略

针对不同采集条件下手部旋转、尺度和摆放不一致的问题，NFPH引入基于关键点的空间变换策略。通过对五指方向进行对齐、对各区域进行裁剪与重采样，将原始手部图像映射至统一坐标空间，显著降低姿态变异带来的特征扰动。

3） 多模态解耦表示

在归一化空间中，分别构建五指拼接图（All Fingers, AF）与手掌图像表示，实现结构化区域表达。该表示方式避免了整体建模中区域信息相互干扰的问题，使不同生物特征能够被独立建模与优化。

通过上述步骤，NFPH实现了”分割—对齐—解耦”的标准化处理流程。

二、全掌认证网络 FPHandNet （Full Palmar Hand Authentication Network）

在NFPH表示基础上，文章提出全掌认证网络 FPHandNet，用于实现多区域结构化特征学习与融合。该网络由三个核心模块构成：

1.手指特征提取模块（FFEM）

FFEM以AF图像为输入，输出五个独立的手指特征向量。具体而言，骨干网络输出特征张量后，沿空间维度划分为五个子区域，每个区域对应一根手指，并分别进行全局平均池化，得到五个特征向量 。

该设计引入”部件级监督策略”，即对每个手指特征单独计算损失函数，强制网络关注各手指的判别信息，避免整体特征学习中出现区域偏置现象。

2.手掌特征提取模块（PFEM）

PFEM对归一化后的手掌图像进行编码，输出手掌特征向量 。与手指模块结构一致，但不进行空间划分，以保留完整掌部纹理结构。

实验结果

为全面验证标准化全掌建模框架 NFPH 及其认证网络 FPHandNet 的有效性，本文在多个公开手部生物识别数据库与不同光谱条件下开展系统实验评估，并与多种主流方法进行对比分析，具体实验设计如下：

  1. 实验数据集

为验证方法的跨光谱适应能力与跨数据库泛化性能，实验选取了多种可见光与近红外手部数据库。

CASIA 多光谱手部数据库： 来自 Chinese Academy of Sciences 发布的 CASIA 数据集包含五种不同光谱条件下的手部图像。实验中将不同光谱子集分别作为独立测试对象，用于评估模型在多光谱环境下的稳定性与判别能力。

SCUT-NFPH 数据集（V 与 N）： 由华南理工大学团队构建，包含可见光（V）与近红外（N）两种采集模式，覆盖多身份、多姿态样本。该数据集用于验证标准化全掌建模在不同成像机制下的有效性。

IITD Palmprint 数据集： 该数据库包含大量手掌图像，常用于掌纹识别研究。实验将其纳入对比，用于分析单区域（掌部）与全掌建模的性能差异。

COEP 手部数据库： 包含多用户手部图像数据，采集条件多样，用于测试模型在复杂背景与姿态变化场景下的鲁棒性。

  1. 评价指标与评价标准

为全面衡量认证系统性能，本文从识别精度与模型效率两个维度进行综合评价。识别性能方面采用等错误率（EER）、真实接受率（TAR）以及误接受率（FAR）作为核心指标，其中重点报告 EER 及 TAR@FAR=0.01 以反映系统在低误接受场景下的安全性表现；效率层面则通过模型参数量（Params）与计算复杂度（FLOPs）评估网络规模与计算开销，从而分析方法在实际部署环境中的可行性与资源需求。

  1. 实验环境与参数设置

实验分别在 PaddlePaddle 与 PyTorch 框架下实现，其中分割模块 HSANet 基于 PaddlePaddle 进行训练，认证模块 FPHandNet 基于 PyTorch 构建与优化。所有实验均在 NVIDIA RTX 3090 GPU 上完成。输入图像统一调整为 320 × 320，批处理大小设为 16，总训练轮次为 100 epochs，优化器采用 Adam，初始学习率设置为 0.0001。损失函数采用 ArcFace Loss 与 Center Loss 的联合优化策略，其中 Center Loss 权重 λ 通过网格搜索确定最优取值。为增强模型泛化能力，训练过程中引入多种数据增强策略，包括 0.5–2.0 范围内的随机缩放、随机水平翻转、随机亮度/对比度/饱和度扰动以及通过参数搜索优化范围的随机透视变换。

关键实验与结果

  1. 指静脉冗余分析实验

一、HSANet 分割性能分析

在语义分割任务中，采用 mIoU 与 FPS 作为评价指标，训练测试按 7:3 随机划分。 对比方法包括： OTSU、固定阈值、肤色阈值、U-Net、SegNeXt、TopFormer 以及 SAM。

实验结果表明，传统阈值类分割方法在掌腕边界及指根等复杂区域表现不稳定，整体 mIoU 明显低于深度学习方法；基于卷积结构的 U-Net 与 SegNeXt 虽然能够较好提取手部整体轮廓，但在细粒度边界处仍存在一定模糊与粘连现象；基于 Transformer 的实时分割网络 TopFormer 在推理速度方面具有优势，但精度略逊一筹。相比之下，本文提出的 HSANet 在十个数据库上均取得最高或接近最高的 mIoU，同时保持较高 FPS，表现出更优的综合性能。值得注意的是，即便为预训练的 SAM 引入 prompt 点约束，其仍难以稳定地区分五指与掌部区域。上述结果充分说明，多层上下文特征融合机制与结构约束设计对于提升手部细粒度区域分割精度具有显著作用。

二、解耦手部生物特征认证性能分析

在认证任务中采用 subject-independent 协议（5:5 身份划分），构造等数量 genuine / imposter 配对。评价指标包 括 EER 与 TAR@FAR=0.01。

在单区域性能分析中，实验系统比较了五指与掌部在纹理、静脉以及形状特征条件下的识别表现。结果显示，拇指在各数据库上的 EER 普遍较高，判别能力弱于其余四指，而其余四指之间性能差异不显著；将五指信息整体拼接形成的 All Fingers（AF）特征整体优于任一单指特征，体现出多指协同建模的优势。在仅使用静脉或纹理特征时，AF 与掌部区域的性能基本相当，但在融合形状特征后，AF 的识别性能显著优于掌部，说明结构化多指表示在综合特征建模中更具判别潜力。

进一步分析形状特征的贡献可以发现，在近红外条件下，AF 融合形状信息后平均 EER 降低 1.03%，掌部区域平均降低 1.82%；而在可见光条件下，AF 的平均 EER 降低 1.91%，掌部仅降低 0.35%。该结果表明，经过标准化几何对齐后的形状信息能够有效补充纹理与静脉特征，尤其在可见光环境下对多指结构的增强作用更为明显，从而显著提升整体认证性能。

三、消融实验分析

（1）手部归一化有效性验证

比较了 All Fingers（AF）与 Palm 区域在几何归一化前后的认证表现。实验结果显示，两类区域在归一化处理后 EER 均出现明显下降，其中 AF 的性能提升幅度大于 Palm。通过指间方向平行对齐与统一尺度重采样，类内姿态差异得到有效抑制，特征分布更加集中，判别特征提取过程更加稳定。该结果验证了 NFPH 几何归一化策略在降低类内姿态扰动、提升特征一致性方面的关键作用。

（2）部件级监督策略验证

保持 FPHandNet 整体结构不变的前提下，移除五指独立监督，仅对五指特征求平均后进行损失计算。结果表明，引入 ArcFace 与 Center Loss 的联合优化可使平均 EER 降低 1.22%，在此基础上进一步加入部件级监督后，EER 再下降 1.11%，而所有消融模型的性能均出现不同程度退化，说明各模块设计具有必要性。结合 Grad-CAM 与 SHAP 可视化分析发现，未使用部件监督时网络注意力主要集中于少数手指区域，而加入部件级监督后注意力在五指之间分布更加均匀，多指判别信息得到更充分利用，表明该策略显著增强了多区域信息的协同建模能力。

四、与现有方法对比分析

在与现有方法对比分析中，本文构建了三条对比管线以验证 NFPH + FPHandNet 的综合性能：Pipeline 1 为传统 ROI 提取后分别建模并进行分数级融合；Pipeline 2 使用 NFPH 提取的标准化区域分别建模并进行分数融合；Pipeline 3 则实现 NFPH + FPHandNet 的端到端结构融合。对比方法包括传统特征方法 CompCode 以及多种深度方法 CCNet、AMPVNet 与 FasterNet-T1。ROC 曲线分析结果表明，所有深度方法在 Pipeline 2 与 3 中均优于 Pipeline 1，而 CompCode 在各数据库上的表现明显落后于深度方法；Pipeline 3 的精度接近 Pipeline 2，同时整体优于 Pipeline 1，ROC 曲线整体向左上方靠近，说明在保持低误接受率的同时仍能维持高真实接受率。

在计算复杂度对比方面，Pipeline 3 的 FLOPs 仅为 Pipeline 1 与 2 的约三分之一，显示 FPHandNet 在结构层面实现了高效融合，同时多模态信息在统一网络中共享编码，显著减少了重复计算。在保证精度的前提下，该管线大幅降低了计算成本，系统性实验结果验证了 NFPH + FPHandNet 在准确性、稳定性与效率方面相较现有方法的综合优势，展现出良好的工程部署价值与推广潜力。

结论

本文提出了一种标准化全掌多模态身份认证框架 NFPH 及其对应的全 掌认证网络 FPHandNet，能够系统性地建模五指与手掌之间的结构关系，并有效缓解姿态变化与区域耦合带来的性能退化问题。针对传统整体建模缺乏空间规范、部件判别能力不足的问题，本文通过”语义分割—几何归一化—区域解耦”的标准化流程，将原始手部图像映射至统一坐标空间，从源头降低类内差异，提高特征表达的稳定性与一致性。

在特征学习阶段，FPHandNet 通过手指特征提取模块与手掌特征提取模块分别建模不同区域的判别信息，并引入部件级监督策略，对五个手指特征分别施加 ArcFace Loss 与 Center Loss 的联合约束，以增强类间分离度并压缩类内分布。多特征融合模块对六个区域特征进行结构化拼接，实现全掌信息的协同判别。该设计避免了单一全局特征学习中的区域偏置问题，使网络能够自动强化判别力更强的局部区域，同时保持整体结构信息的完整性。

此外，联合损失函数在角度间隔约束与类中心约束的共同作用下，显著提升了嵌入空间的判别结构稳定性。部件级监督与特征融合机制相结合，使模型在复杂光谱条件与跨数据库场景下仍具备良好的泛化能力。

在多个公开与自建数据库上的实验结果表明，所提出方法在等错误率（EER）、HTER 及固定 FAR 条件下的识别率均优于主流对比方法，同时保持合理的参数规模与计算复杂度。综合来看，本文构建的标准化全掌建模框架为手部多模态生物识别提供了一种统一、稳定且高判别力的解决方案，对后续跨模态融合与结构化生物特征建模研究具有重要参考价值。
