Advanced Science | 基于注意力转移的可穿戴脑机接口晕车干预系统

该论文发表于Advanced Science（中科院1区Top，IF=14.1），题目为《A Wearable Brain-Computer Interface for Mitigating Car Sickness via Attention Shifting》。

华南理工大学的朱嘉炜博士和包晓雨博士为本文共同第一作者，通讯作者为华南理工大学、人工智能与数字经济广东省实验室（广州）、华南脑控（广东）智能科技有限公司的李远清教授。合作单位还包括德赛西威汽车电子股份有限公司、华南师范大学人工智能学院以及上海交通大学医学院。

论文链接

http://doi.org/10.1002/advs.202513040

论文概要

晕车是困扰现代人出行的常见问题。吃药虽能缓解，但嗜睡、口干等副作用让人望而却步；其他非药物方法又缺乏可靠验证。华南理工大学李远清教授团队最新发表于 Advanced Science 的研究，带来了一款 可穿戴正念冥想脑机接口系统 ——它像一位随行的”数字冥想导师”，通过实时读取脑电波，帮助用户把注意力从晕车的不适感中”抽离”出来，转移到正念练习上。

研究团队招募了 106名易晕车志愿者 ，在真实道路环境中完成了两项实验：20分钟短途乘车和120分钟长途乘车。结果显示， 超过83%的参与者认为该方法有效 ，且晕车越严重的人，改善效果越明显。更关键的是，团队还发现了 晕车相关的脑电”指纹”——前额叶β波相对能量 ，为这项技术为何有效提供了科学依据。

研究背景：为什么晕车这么难缠？

晕车（Car Sickness）是典型的晕动症，轻则头晕出汗，重则恶心呕吐。数据显示， 全球近46%的人过去五年经历过晕车 ，12%的成年人频繁发作，儿童比例更高。

目前主流解决方案是药物（如茶苯海明、东莨菪碱），有效率约62%-78%，但副作用明显——嗜睡、头痛、视物模糊，很多人宁愿硬扛也不愿吃。非药物方法也有尝试：给视觉提示帮助大脑预判运动、引导做深呼吸、或通过心率等生理信号进行生物反馈。其中， “注意力转移法” 看似简单，但在颠簸的车厢里持续专注并不容易，效果也缺乏严格验证。

核心难题在于： 如何让乘客在动态环境中，持续、稳定地将注意力从”我好晕”转移到”我要专注”？

研究方法：一个会”读心”的冥想助手

李远清团队创新性地将正念冥想与脑机接口技术相结合，打造出一套”懂大脑、会反馈”的智能系统。这套系统由三部分组成：一条轻便的脑电采集头环、运行智能算法的客户端软件、以及沉浸式的视听反馈界面。

头环仅重约50克，续航达8小时，采用干电极设计，佩戴舒适。它采集前额叶Fp2位置的脑电信号，通过蓝牙实时传输至手机或电脑。系统的核心是一个预训练的跨被试卷积神经网络——它无需针对个人校准，就能将复杂的脑电信号转化为直观的”冥想分数”（0-100分）。分数越高，代表用户越放松、越专注。

分数实时驱动着冥想场景的变化。系统提供海浪、篝火、听觉冥想、沙漠等多种主题。以”篝火冥想”为例：当用户专注呼吸、心神宁静时，火焰会愈燃愈旺，木柴噼啪声愈发清晰；一旦思绪飘走，画面便暗淡下去。这种即时反馈如同一位无声的冥想教练，帮助用户觉察状态、调整呼吸，将注意力稳稳锚定在当下，自然远离身体的不适感。

值得一提的是，这套系统完全兼容Windows、Android和iOS，普通手机即可运行。用户只需约20分钟培训就能上手，真正做到了”开箱即用”。

为验证效果，研究团队严格筛选了106名易晕车志愿者（MSSQ-Short问卷得分前25%），在广州市区的真实道路上开展了两项实验。

图 1 正念冥想脑机接口系统

实验一（短途乘车） 采用交叉设计：每位参与者完成两个40分钟的实验阶段，每个阶段包含连续两段20分钟车程——一段正常使用脑机接口系统，一段自然乘车不做干预。两个阶段中两种状态的顺序相反，以消除顺序效应。研究人员每2分钟记录一次晕车严重程度评分（MISC，0-10分，分数越高症状越重）。

实验二（长途乘车） 进一步考验系统的耐久性。101名志愿者（5人因恐惧长途退出）分别完成两段120分钟的真实车程，一段使用系统，一段自然乘车，顺序随机平衡，每10分钟记录症状评分。

实验结果

（1）有效缓解短途与长途晕车症状

实验一中，89名参与者（83.96%）明确表示该方法有效。统计分析显示，使用脑机接口系统的MISC评分显著低于自然乘车状态（两因素方差分析，状态主效应：F(1,420) = 35.731, P < 0.001），效果不受实验顺序影响，平均降低0.702个标准差（配对t检验：t(105) = -7.230, P < 0.001, Cohen’s d = -0.702）。这意味着，短短20分钟的干预就能带来中等到大效应量的症状改善。

实验二中，90名参与者（89.11%）报告有效。线性混合模型显示，系统能显著降低全程的MISC评分（状态主效应：F(1,2600) = 584.325, P < 0.001），且从第10分钟起效果持续显著（状态×时间交互效应：F(12,2600) = 6.817, P < 0.001）。与自然乘车相比，使用系统的平均MISC评分降低了1.219个标准差（配对t检验：t(100) = -12.251, P < 0.001, Cohen’s d = -1.219），属于大效应量。更难得的是，自然乘车状态下症状随时间逐渐加重，而使用系统时这一趋势被明显遏制。

图 2 短途与长途乘车实验中MISC分数的结果

（2）症状越重，效果越好

一个有趣的发现是：晕车越严重的人，反而越能从这项技术中受益。研究者根据自然乘车状态下的平均MISC评分，将参与者分为轻症组（2-4分）和重症组（4-10分）。

在实验一中，轻症组的缓解比例为72.92%，重症组则达到100%；平均MISC评分下降幅度，轻症组为1.02分，重症组达2.31分。实验二呈现同样规律：轻症组缓解率85.71%，重症组100%；评分下降幅度分别为1.68分和2.72分。对于平时晕车最严重的人群（最高MISC≥7分），系统带来的改善尤为显著——实验二中，这类参与者的平均最高分从7.68分降至4.43分，有3名因严重不适无法完成自然乘车的志愿者，却顺利完成了系统辅助下的全程。

图 3 基于自然乘车晕车严重程度分组的症状缓解结果

（3）发现晕车的脑电”指纹”

脑电分析揭示了晕车的神经标记：前额叶β波相对能量（即β波段功率占全频带的比例）。无论在短途还是长途实验中，这一指标都与MISC评分的变化呈显著负相关——β相对能量越低，晕车症状越重。这一规律在自然乘车和系统使用状态下均稳定存在，表明它是反映晕车严重程度的可靠生理指标。

图 4 前额β相对能量与MISC分数的变化在短途（A, B）与长途（C, D）实验中均呈显著负相关

（4）系统能主动调节脑电标记

更重要的是，这套系统能够”逆转”晕车的脑电特征。实验一中，使用系统时的前额叶β相对能量显著高于自然乘车状态（两因素方差分析：F(1,404) = 17.851, P < 0.001），效应量中等（Cohen’s d = 0.446）。两种状态下的β能量差值与症状差值显著负相关（r = −0.324, P < 0.001）——系统提升β能量越多，症状减轻越明显。实验二复现了这一发现（t(96) = 3.068, P = 0.003, Cohen’s d = 0.311；相关性r = −0.209, P = 0.040）。

结合感官冲突理论，研究者解释了这一现象：晕车源于视觉、前庭觉与本体感觉的信息冲突。正念冥想是一种典型的”自上而下”认知控制过程，能增强前额叶对感觉信息的整合能力，表现为β波段能量提升；而系统通过实时反馈帮助用户维持深度冥想状态，从而有效缓解感官冲突。

图 5 脑机接口注意力转移方法显著提升前额β相对能量

（5）确保持续注意力投入

如何证明参与者真的在认真冥想，而非被动观看画面？theta/alpha功率比值提供了证据。这一指标是公认的注意力神经标记，比值越低代表注意力越集中。实验一中，系统使用状态下的theta/alpha显著低于自然乘车（F(1,404) = 103.687, P < 0.001），效应量接近1.0（Cohen’s d = -0.973）。实验二同样观察到显著差异（t(96) = -5.064, P < 0.001, Cohen’s d = -0.514）。这表明，无论是在20分钟短途还是2小时长途，参与者都能借助系统维持稳定的专注状态，实现真正的注意力转移。

图 6 冥想分数及和脑电theta/alpha结果

结论

这项发表于《Advanced Science》的研究，首次将脑机接口技术成功应用于晕车干预，并在真实场景中完成了百人规模验证。其核心创新在于：通过闭环神经反馈，解决了传统注意力转移法”难以持续”的痛点；通过发现前额叶β相对能量这一神经标记，为技术效果提供了机制解释。

对亿万晕车人群而言，这意味着一种无副作用、即时起效、便携易用的解决方案已触手可及。对脑机接口领域而言，这项工作拓展了技术应用的新边界——从医疗康复走向日常健康，从实验室走向汽车座舱。未来，随着硬件进一步小型化、成本降低，”防晕车头环”或许将成为智能座舱的标配，让每一次出行都从容自在。
